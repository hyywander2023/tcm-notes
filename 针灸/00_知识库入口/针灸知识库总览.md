# 针灸知识库 · 总览

> 收历代针灸专著 16 部、约 170 万字、309 文件（另有等量整理本）。
> 与伤寒、温病、内经三库同处一个 vault（`D:\中医`），可双链互通。总入口见 [[总库地图]]。

## 一、这个库和内经库是什么关系

针道的根在《内经》，尤其《灵枢》——**《灵枢》别名《针经》**，九针、经脉、经筋、刺法的主体都在那里。
但本 vault 的 [[内经知识库总览|内经库]] **缺《灵枢》白文**，只有张隐庵集注本。

所以这两个库有一条很实际的互助通道：

| 你要 | 去哪 |
|------|------|
| 针刺理论源头（九针、经脉、刺法） | 内经库 → [[灵枢集注·九针十二原第一\|灵枢集注]] |
| 灵枢古传文字的**另一个版本** | 本库 → [[甲乙经·卷首\|针灸甲乙经]]（皇甫谧把《针经》《素问》《明堂孔穴》分类重编，保留大量灵枢原文） |
| 具体穴位、取穴、刺灸操作 | 本库 |
| 歌诀记诵 | 本库 → [[百家歌赋·百症赋\|百家歌赋]]、[[针灸大全·卷首\|针灸大全]] |
| 因病配穴、临床思路 | 本库 → [[资生经·卷首\|资生经]]、[[针灸逢源·卷首\|针灸逢源]] |

> [!tip] 一条实用校勘路子
> 灵枢某句读不通时，去甲乙经找对应条文——两书同源而异文，异文处往往正是理解分歧所在。
> 这也是本 vault 用"一个库装四家"最划算的地方。

## 三、建库五条原则

1. **原文一字不改**。底本存原貌，整理本只重排版式。录入痕迹见 [[针灸文本校勘总表]]。
2. **歌赋单独看重**。针灸的传承有很大一部分靠韵文背诵（标幽赋、金针赋、百症赋、玉龙歌），
   这些不是"通俗读物"，是**技术纲领的口诀化**。读赋要逐句拆到穴位与手法。
3. **同名穴、同名方须标出处**。同一穴在不同书里取法有差，同一手法各家描述不同，
   卡片上必须写清"据某书某卷"。
4. **临床书与理论书分读**。资生经、逢源是"病了怎么取穴"，甲乙经、素难要旨是"理从哪来"。
5. **不确定就写"存疑"**。针灸古籍版本歧异极大（尤其穴位数、禁针穴），没有版本依据不下断语。

## 四、三条阅读路线

### 路线 A：入门（约 1 周）

1. [[百家歌赋·四总穴歌|四总穴歌]]、[[百家歌赋·百症赋|百症赋]]、[[百家歌赋·针经标幽赋|标幽赋]]——先背纲领
2. [[针灸易学·卷首|针灸易学]]——清人入门教材，取穴手法讲得直白
3. 回 [[针灸大成·第01部|针灸大成]] 卷一、卷二看针道源流与手法

### 路线 B：正经读《大成》（按月计）

十卷，本库按约 2 万字切成 15 个"部"，每部内部用 `##` 保留原篇名：

| 部 | 大致内容 |
|----|----------|
| 第01–02 部 | 卷一、卷二：针道源流、针灸直指、刺法各论 |
| 第03–06 部 | 卷三至卷五：十二经穴、奇经八脉、特定穴 |
| 第07–11 部 | 卷六至卷八：脏腑、证治、穴法 |
| 第12–15 部 | 卷九至卷十：治症总要、小儿按摩、附方 |

> [!note] 聚合单元不是原书卷次
> 每部顶部都有一行「阅读聚合单元」说明，写明起止篇名与节数。要按原书卷次找，用 `## 卷X` 标题定位。
