# 知识库使用说明（针灸版）

> 与伤寒版、温病版、内经版是同一套目录规则的第四个副本。同名不同内容，双链时请注明"针灸版"。
> 通用部分（目录、front matter、操作权限）见 [[内经/00_知识库入口/知识库使用说明|内经版]]，这里只写针灸库不同的地方。

## 一、最要紧的一条：聚合单元怎么链

针灸书大多切成「第NN部」，不是一篇一文件。双链写法：

```
[[针灸大成·第03部]]            整部
[[针灸大成·第03部#百症赋]]       部内某节（## 标题）
[[针灸大成·第03部#卷五]]         按原书卷次定位
```

**链到节比链到部好**。部是机器切的阅读单元，节才是原书结构。

每部顶部有一行说明，写明本部的起止篇名、节数、字数——切片时先看这一行，就知道这 2 万字收了什么。

```
> **阅读聚合单元**（约 19 千字，26 节）：起「卷一」，止「刺法论」，非原书卷次。篇目：…
```

> [!warning] 「第NN部」不是原书卷次
> 《针灸大成》原书十卷，本库切成 15 部，两者不对应。
> 想按原书卷次读，找部内的 `## 卷一`「## 卷二」标题。

## 二、按篇切的书

只有三部：**甲乙经、针灸问对、子午流注针经**。它们篇自足，一篇一文件：

```
甲乙经·精神五脏论第一.md
针灸问对·三才法.md
子午流注·五子元建日时歌.md
```

## 三、歌赋书

`百家歌赋` 一首一文件，文件名即赋名：

```
百家歌赋·针经标幽赋.md
百家歌赋·四总穴歌.md
```

双链写 `[[百家歌赋·针经标幽赋]]`。注意「标幽赋」的全名是「针经标幽赋」，`[[标幽赋]]` 解析不到。

## 四、front matter 字段

```yaml
---
类型: 原始资料
书名: 针灸大成
简称: 针灸大成
聚合单元: 第03部         # 只有聚合本有；一篇一文件的书改用「篇: XXX」
作者: 杨继洲
朝代: 明
成书: 公元1601年
来源: 中华医典数字化文本（299-针灸大成）
备注: 版本说明
---
```

针灸书原文里没有 `<目录>卷N` 这类卷次标记（与素问不同），所以**没有 `卷:` 字段**。
卷次信息保留在正文的 `## 卷X` 标题里。

## 五、穴位引用约定

针灸的引用单位是**穴 + 书 + 卷**，三者缺一不可。同穴不同法的例子太多：

| 场景 | 写法 |
|------|------|
| 某穴在某书的定位 | 「据《甲乙经》卷三」→ `[[甲乙经·卷首]]`（先记篇名再补卷） |
| 某穴的取法分歧 | 「《大成》作 X，《资生经》作 Y」——两处都链 |
| 禁针禁灸 | 各家分歧最大，必须逐条标出处，不许写"一般认为" |

## 六、插图缺失（本库最严重的短板）

针灸书的价值一半在图上。转码文本有 **554 处插图占位**，**图片文件全部没有**：

| 书 | 插图数 |
|----|--------|
| 针灸大成 | 151 |
| 杨敬斋针灸全书 | 149 |
| 针灸易学 | 54 |
| 针灸逢源 | 38 |
| 针灸资生经 | 36 |
| 针灸聚英 | 35 |
| 针灸大全 | 33 |
| 子午流注针经 | 28 |
| 普济方·针灸 | 9（去重后） |
| 其他 | 21 |

已就地标注为：

```
［原书插图：仰人周身总穴图　原件 pG-G1.bmp，图片未随文本提供］
```

> [!warning] 看到这个标注要知道什么
> 1. **这处原书有图，图上往往才是关键信息**（穴位位置、经脉走向、九针形制）
> 2. 图文对照的段落，文字往往只是图注，单看文字会读不懂
> 3. 需要图时，只能回原书或另找带图版本，本库给不了
