# 针灸文本校勘总表

> [!warning] 这份表能做什么、不能做什么
> 记的是**转码暴露的问题**：编码、标记、插图、重复篇、作者字段。
> **没有**拿通行本（人民卫生出版社校注本、中国中医药出版社本等）逐字对校。
> 标「存疑」的都没核实，别当定论用。

## 一、底本性质

中华医典数字化文本，GB18030 → UTF-8。保留定宽硬换行。全部 16 部同一来源、同一格式。

## 二、五类录入痕迹

| 类型 | 示例 | 针灸库规模 | 处理 |
|------|------|-----------|------|
| `∶` 代冒号 | `大椎∶` `刺之∶` | 5,747 处 | 不改 |
| `根据` 代「依」 | `根据法取之` | 407 处 | 不改 |
| `浓` 代「厚」 | `浓煎` | 201 处 | 不改 |
| 夹空格 | `大椎 陶道 身柱` | 15,968 处 | **绝大多数是正常间隔**，见下 |
| 插图占位 | `［原书插图：…］` | **554 处** | 已标注，图未入库 |

### 夹空格：针灸书里基本不是缺字

16,000 处夹空格，绝大部分是**穴位列举的间隔**：

```
偃伏头部中行十穴  神庭 上星 囟会 前顶 百会
```

这类空格是原书的分栏排法，不是缺字，**不要当讹误处理**。
真正的缺字（形如 `禁 穴`）数量少，须结合上下文判断。

## 三、最严重的问题：554 处插图全部缺失

针灸书的价值一半在图上。原文本只有占位标记，**没有一张图片**。

| 书 | 插图 | 图的重要性 |
|----|------|-----------|
| 针灸大成 | 151 | 周身总穴图、十四经穴图——全书骨架 |
| 杨敬斋针灸全书 | 149 | 本书以图为主，**无图即失大半** |
| 针灸易学 | 54 | 取穴图、脉图 |
| 针灸逢源 | 38 | 运气图为主 |
| 针灸资生经 | 36 | 分经列穴图 |
| 针灸聚英 | 35 | 脏腑图、经穴图 |
| 针灸大全 | 33 | 量穴法图、尻神图 |
| 子午流注针经 | 28 | 五输穴图、流注图 |
| 其他 | 30 | — |

已就地转成：

```
［原书插图：仰人周身总穴图　原件 pG-G1.bmp，图片未随文本提供］
```

## 四、重复篇名与合并

中华医典把穴名、证名、凡例都当 `<篇名>`。同名块已合并，正文依次拼接，不删内容：

| 书 | 原篇块 | 重名对数 | 合并后 |
|----|--------|----------|--------|
| 针灸集成 | 268 | 27 对 | 9 部 |
| 普济方·针灸 | 575 | 19 对 | 21 部 |
| 针灸逢源 | 319 | 11 对 | 13 部 |
| 针灸神书 | 427 | 12 对 | 4 部 |
| 针灸聚英 | 255 | 5 对 | 8 部 |
| 甲乙经 | 144 | 1 对 | 136 文件 |

重名集中在「手太阴肺经」「禁针穴歌」「禁灸穴」这类——**不同卷里重复出现同一标题**，
合并后它们在同一文件内，用 `##` 标题分隔，读到时要看上下文判断是哪一卷的。

## 八、建穴位卡时新发现的底本缺陷

建 361 张穴位索引卡的过程中，暴露出四处**底本自身**的问题。这些不是录入痕迹，是这套电子文本的实质残缺，直接影响「能不能查到」，必须记下来。

### 1. 《甲乙经》缺手三阴三阳「及臂」五篇

《针灸甲乙经》卷三按经脉列穴，但底本**整篇缺失**以下五篇（原始 txt 中即无 `<篇名>` 标记）：

| 缺篇 | 应收穴数 |
|---|---|
| 手太阴及臂凡一十八穴 | 18 |
| 手阳明及臂凡二十八穴 | 28 |
| 手厥阴及臂凡一十六穴 | 16 |
| 手少阳及臂凡三十二穴 | 32 |
| 手少阴及臂凡一十六穴 | 16 |

后果：**合谷、曲池、内关、外关、神门、少泽等手部要穴，《甲乙经》里根本查不到定位描述**。目前这些穴的定位只能靠《针灸大成·考正穴法》与《针灸聚英》补。

> 若要补，需另找《甲乙经》足本（如人民卫生出版社校注本）校补，勿据他书臆造。

### 2. 穴位篇正文只录了约 43%

现存 28 篇穴位篇，篇名标注的穴数合计 **465 穴**，正文实存仅 **200 条**。例如「头直侠督脉各一寸五分却行至玉枕凡十穴第三」，正文只有五处、承光、通天、络却等 5 条。

这不是切分错误——切句后逐条核对，缺的就是缺。

### 3. 「髎」字系统性缺失

全库「髎」字仅出现 **9 次**，「窌」0 次。凡带「髎」的穴名在正文中多被吞成空格：

| 通行名 | 底本实际写法 |
|---|---|
| 瞳子髎 | `瞳子 `（后缺一字） |
| 素髎 | `素 ` |
| 肘髎 | `肘 、五里近`（《大成·手阳明经穴歌》） |
| 肩髎／肩髃 | `臂 、肩 ` |

同类被吞的还有「臑」「郄」「瘈」等。**结果是 14 个穴位在全库检索不到正名**，它们的卡片已建但标注「底本未见此穴名」，需人工按上下文补。

### 4. 同形穴名：三里、临泣、窍阴、通谷、阳关

古书常省称，「三里」既指手三里（曲池下二寸）也指足三里（犊鼻下三寸）。建卡时曾把「三里（一名手三里）∶曲池下二寸」误收进足三里，已修正为按定位语消歧（犊鼻／膝下 → 足三里；曲池／肘 → 手三里）。

其余四组（头临泣／足临泣、头窍阴／足窍阴、腹通谷／足通谷、腰阳关／膝阳关）目前**只统计全名，简称未计入**，卡片里已加注说明。这是已知的统计缺口，不是数据错误。

## 九、校勘原则

1. **底本一字不改**。
2. **改必留痕**，可回查。
3. **存疑不硬断**。
4. **图与文分开标注**。现代补图不许冒充原书图。
