# 针灸文本校勘总表

> [!warning] 这份表能做什么、不能做什么
> 记的是**转码暴露的问题**：编码、标记、插图、重复篇、作者字段。
> **没有**拿通行本（人民卫生出版社校注本、中国中医药出版社本等）逐字对校。
> 标「存疑」的都没核实，别当定论用。

## 一、底本性质

中华医典数字化文本，GB18030 → UTF-8。保留定宽硬换行。全部 16 部同一来源、同一格式。

## 二、五类录入痕迹

| 类型 | 示例 | 针灸库规模 | 处理 |
|------|------|-----------|------|
| `∶` 代冒号 | `大椎∶` `刺之∶` | 5,747 处 | 不改 |
| `根据` 代「依」 | `根据法取之` | 407 处 | 不改 |
| `浓` 代「厚」 | `浓煎` | 201 处 | 不改 |
| 夹空格 | `大椎 陶道 身柱` | 15,968 处 | **绝大多数是正常间隔**，见下 |
| 插图占位 | `［原书插图：…］` | **554 处** | 已标注，图未入库 |

### 夹空格：针灸书里基本不是缺字

16,000 处夹空格，绝大部分是**穴位列举的间隔**：

```
偃伏头部中行十穴  神庭 上星 囟会 前顶 百会
```

这类空格是原书的分栏排法，不是缺字，**不要当讹误处理**。
真正的缺字（形如 `禁 穴`）数量少，须结合上下文判断。

## 三、最严重的问题：554 处插图全部缺失

针灸书的价值一半在图上。原文本只有占位标记，**没有一张图片**。

| 书 | 插图 | 图的重要性 |
|----|------|-----------|
| 针灸大成 | 151 | 周身总穴图、十四经穴图——全书骨架 |
| 杨敬斋针灸全书 | 149 | 本书以图为主，**无图即失大半** |
| 针灸易学 | 54 | 取穴图、脉图 |
| 针灸逢源 | 38 | 运气图为主 |
| 针灸资生经 | 36 | 分经列穴图 |
| 针灸聚英 | 35 | 脏腑图、经穴图 |
| 针灸大全 | 33 | 量穴法图、尻神图 |
| 子午流注针经 | 28 | 五输穴图、流注图 |
| 其他 | 30 | — |

已就地转成：

```
［原书插图：仰人周身总穴图　原件 pG-G1.bmp，图片未随文本提供］
```

## 四、重复篇名与合并

中华医典把穴名、证名、凡例都当 `<篇名>`。同名块已合并，正文依次拼接，不删内容：

| 书 | 原篇块 | 重名对数 | 合并后 |
|----|--------|----------|--------|
| 针灸集成 | 268 | 27 对 | 9 部 |
| 普济方·针灸 | 575 | 19 对 | 21 部 |
| 针灸逢源 | 319 | 11 对 | 13 部 |
| 针灸神书 | 427 | 12 对 | 4 部 |
| 针灸聚英 | 255 | 5 对 | 8 部 |
| 甲乙经 | 144 | 1 对 | 136 文件 |

重名集中在「手太阴肺经」「禁针穴歌」「禁灸穴」这类——**不同卷里重复出现同一标题**，
合并后它们在同一文件内，用 `##` 标题分隔，读到时要看上下文判断是哪一卷的。

## 五、非底本材料

| 书 | 问题 |
|----|------|
| 百家针灸歌赋 | 现代辑本（"举拙修订版"），**不是中华医典底本**。歌赋文字与《大成》《聚英》所引常有出入 |
| 普济方·针灸 | 从《普济方》抽出，非独立成书，篇次为整理者所定 |

## 六、重复源文件

```
316-普济方·针灸.txt        725,279 字节
316-普济方·针灸 (1).txt    725,279 字节   ← 逐字节相同
```

入库只用了前者。原文件夹里的副本**未删除**。

## 七、待核清单

以下问题**尚未核实**，读到时须查通行本：

- [ ] 《针灸神书》作者与年代（宋/元/明诸说并存）
- [ ] 《杨敬斋针灸全书》署名"陈言"——宋·陈言（《三因极一病证方论》作者）与明·陈言是否同一人
- [ ] 《普济方·针灸》的抽取标准（哪些门属针灸，整理者如何取舍）
- [ ] 各书穴位数与通行本的差异（尤其禁针穴、禁灸穴的数目）
- [ ] 甲乙经与灵枢的异文——这是**最值得做的一项**，两书同源，异文即分歧点

## 八、校勘原则

1. **底本一字不改**。
2. **改必留痕**，可回查。
3. **存疑不硬断**。
4. **图与文分开标注**。现代补图不许冒充原书图。
