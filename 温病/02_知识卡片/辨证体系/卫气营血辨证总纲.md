# 卫气营血辨证总纲

> [!info] 本卡的定位
> 卫气营血是温病的**横向坐标**（辨深浅），三焦是**纵向坐标**（辨部位）。本卡只管横坐标；两套坐标如何合看，见 [[三焦辨证总纲]]（待建）。

## 一、纲领原文

> [!quote] 叶天士《温热论》第一章
> 温邪上受，首先犯肺，逆传心包。肺主气属卫；心主血属营。辨营卫气血虽与伤寒同；若论治法，则与伤寒大异。

> [!quote] 叶天士《温热论》第六章
> 大凡看法：卫之后方言气，营之后方言血。在卫汗之可也；到气才宜清气；乍入营分，犹可透热，仍转气分而解……至入于血，则恐耗血动血，直须凉血散血。

**出处**：[[温热论·第一章·温病大纲]]、[[温热论·第六章·卫气营血看法]]

## 二、四层对照

| | 卫分 | 气分 | 营分 | 血分 |
|---|---|---|---|---|
| **病位** | 肺卫、皮毛 | 肺、胃、肠、胆、三焦 | 心包、营阴 | 心、肝、肾、血分 |
| **主症** | 发热，微恶风寒，头痛，咳嗽，口渴，无汗或少汗 | 壮热，不恶寒反恶热，大汗，大渴，脉洪大（或潮热便秘、腹满痛） | 身热夜甚，心烦不寐，时有谵语，斑疹隐隐 | 斑疹透露，吐血、衄血、便血，或昏狂谵妄，舌紫暗 |
| **舌** | 舌尖边红，苔薄白 | 舌红，苔黄 | 舌绛，少苔或无苔 | 舌深绛或紫暗 |
| **脉** | 浮数 | 洪大 / 沉实 / 滑数 | 细数 | 细数或芤 |
| **治法** | 辛凉解表（汗） | 清热（清） | 清营透热（透） | 凉血散血 |
| **代表方** | 银翘散、桑菊饮 | 白虎汤、承气汤 | 清营汤、安宫牛黄丸 | 犀角地黄汤 |

## 三、辨证要点

1. **先分表里**：卫分有恶寒，气分不恶寒反恶热。这是第一刀。
2. **再分气血**：营分舌绛、心烦不寐、斑疹隐隐；血分则见出血、舌紫暗、神昏狂乱。
3. **辨"截断"**：卫→气可顺，卫→营为逆（[[逆传心包]]）。见卫分证而神志已变，即须防逆传。
4. **层次可兼**：临床多见气营两燔、气血两燔，不可硬按单层治。

## 四、与伤寒六经的关系

| | 伤寒六经 | 温病卫气营血 |
|---|---|---|
| 立论依据 | 经络脏腑、寒邪伤阳 | 脏腑气血、温邪伤阴 |
| 传变 | 循经传（太阳→阳明→少阳→三阴） | 由浅入深（卫→气→营→血），可逆传 |
| 治法总则 | 扶阳、和解、温补 | 清热、透邪、养阴 |
| 共同点 | 均为外感病的辨证框架，均以证候群定层次 | 同 |

叶氏自己说"辨营卫气血虽与伤寒同"，指的是**都以层次辨深浅**这一方法论相同；"治法大异"，指的是**寒温异治**。

## 六、我的理解 / 存疑

- **存疑**：卫气营血与三焦孰为纲？教材多主张"以卫气营血为纲、三焦为目"，但吴鞠通全书以三焦立篇。这可能不是理论分歧，而是**叙述方便**的不同（叶氏讲辨治，吴氏讲病位）。待读《温病条辨·卷四·杂说》"本论起银翘散论"后再定。
- **存疑**：营分与心包是否等同？（见 [[逆传心包]] 卡）
