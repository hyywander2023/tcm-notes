# 阳明里结与下法

## 一、纲领原文

> [!quote] 叶天士《温热论》第五章
> 里结于何？在阳明胃与肠也。亦须用下法，不可以气血之分，谓其不可下也。惟伤寒热邪在里，劫烁津液，下之宜猛；此多湿热内抟，下之宜轻。

> [!quote] 叶天士《温热论》第五章
> 必验之于舌：或黄或浊，可与小陷胸汤或泻心汤……须要有地之黄，若光滑者，乃无形湿热，已有中虚之象，大忌前法。

**出处**：[[温热论·第五章·里结阳明]]

## 二、温病下法与伤寒下法

| | 伤寒阳明腑实 | 温病里结 |
|---|---|---|
| 病机 | 热邪在里，劫烁津液，燥屎内结 | 湿热内抟，黏滞不畅 |
| 下法 | **宜猛**（大承气） | **宜轻**（小承气、槟榔、青皮、枳实、元明粉、生首乌） |
| 便溏之义 | 邪已尽，不可再下 | **邪未尽**，必大便硬乃为无湿 |
| 目标 | 攻下燥屎 | 通导湿热，不可伤中 |

> [!warning] 同一个"大便溏"，两种相反判断
> 伤寒见溏＝邪已排出；湿温见溏＝湿尚未化。这是温病下法最容易出错的地方。

## 三、凭舌定下——本章的技术核心

| 舌象 | 判断 | 处理 |
|------|------|------|
| 黄或浊，**有地**（有根） | 实热可泄 | 小陷胸汤 / 泻心汤 |
| 黄而**光滑无地** | 无形湿热兼中虚 | **大忌苦泄** |
| 白苔不燥 | 非实热 | 不可苦泄 |
| 黄白相兼 | 表邪未解里先结 / 邪郁未伸 | 不可苦泄 |
| 灰白不渴 | 素属中冷 | 不可苦泄 |
| 黄甚 / 如沉香色 / 灰黄色 / 老黄色 / 中有断纹 | 邪已入里 | **当下** |
| 未现上述舌象 | — | 不宜用下药 |

**"有地无地"是本卡的核心术语**：苔有根、紧贴舌面如从舌里长出，是邪实；苔浮而光滑、一刮即去，是无形之湿热，多兼中虚。

## 四、不可下而见痞痛，怎么办

脘中痞痛而舌不具下证者，用**开泄**，不用苦泄：

> 宜从开泄，宣通气滞以达归于肺，如近世之杏、蔻、橘、桔等，轻苦微辛，具流动之品可耳。

- 苦泄（黄连、陷胸、泻心）——直折，用于有形实热。
- 开泄（杏、蔻、橘、桔）——流动气机，用于无形湿滞。
- 二者目标不同：一个是"泄掉"，一个是"转开"。

## 五、下后变证与禁忌

- 下之过早、过猛 → 伤中阳、引邪内陷。
- 湿聚太阴为满、寒湿错杂为痛、气壅为胀 → 皆似里结而非里结，当以别法。
- 表症尚存（十之一二）者，不可纯下。

## 六、各家异同

| 书 | 说法 | 差异 |
|----|------|------|
| 温热论 | 下之宜轻，凭舌定下 | 提出"有地无地"标准 |
| 温疫论 | "注意逐邪勿拘结粪"，邪去为度 | 吴又可更激进：不待燥屎即下 |
| 温病条辨 | 中焦篇立承气诸方，增宣白承气、导赤承气、牛黄承气、增液承气 | 从"下"扩展到"通"与"润" |
| 温热经纬 | 王孟英多反对轻下 | 更保守，可对读 |

> [!note] 一个值得追的线索
> 吴又可"勿拘结粪"与叶氏"必验之于舌"，看似相反，实则都在纠正"必待燥屎"的旧说。二者的差别是**以证为据**还是**以舌为据**。这一条可以单独做一张比较卡。

## 七、我的理解 / 存疑

- **存疑**："必大便硬，乃为无湿"是否过绝对？湿温后期脾虚者常先硬后溏。
- **存疑**：五种可下舌象中"中有断纹"，一般作津伤燥裂，亦有作胃气将绝者。两说相去甚远，待核注家。
- 「小承气汤，用槟榔、青皮、枳实、元明粉、生首乌等皆可」——底本此句疑为并列而非同方，存疑。
