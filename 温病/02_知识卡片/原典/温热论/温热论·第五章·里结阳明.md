# 温热论·第五章·里结阳明

## 一、原文（整理本）

> 再论三焦不从外解，必致里结。里结于何？在阳明胃与肠也。亦须用下法，不可以气血之分，谓其不可下也。惟伤寒热邪在里，劫烁津液，下之宜猛；此多湿热内抟，下之宜轻。伤寒大便溏，为邪已尽，不可再下；湿温病大便溏为邪未尽，必大便硬，乃为无湿，始不可再攻也。

> 再人之体，脘在腹上，其位居中，按之痛；或自痛；或痞胀；当用苦泄，以其入腹近也。必验之于舌：或黄或浊，可与小陷胸汤或泻心汤，随证治之。若白（苔）不燥；或黄白相兼；或灰白不渴；慎不可乱投苦泄。其中有外邪未解里先结者；或邪郁未伸；或素属中冷者；虽有脘中痞痛，宜从开泄，宣通气滞以达归于肺，如近世之杏、蔻、橘、桔等，轻苦微辛，具流动之品可耳。

> 前云舌黄或浊，当用陷胸、泻心，须要有地之黄，若光滑者，乃无形湿热，已有中虚之象，大忌前法。其脐以上为大腹，或满或胀或痛，此必邪已入里，表症必无，或存十之一二。亦须验之于舌：或黄甚；或如沉香色；或如灰黄色；或老黄色；或中有断纹。皆当下之，如小承气汤，用槟榔、青皮、枳实、元明粉、生首乌等皆可。若未现此等舌，不宜用此等药。恐其中有湿聚太阴为满；或寒湿错杂为痛；或气壅为胀，又当以别法治之矣。

## 二、校注

- 「若白不燥」：底本如此，疑脱一「苔」字，当作「若白苔不燥」。整理本以括号补，不改字。
- 「灰白不渴」：底本作「或灰 / 白不渴」，为硬换行截断，非两义，整理本合行。
- 「有地之黄」：指苔有根、紧贴舌面如从舌里长出，与"光滑无根"相对。此为本篇辨证关键术语，底本未释。
- 「以其入腹近也」：脘位近腹，故可用苦泄直入。此句历来注家断句不一，此处从通行读法。

## 三、提要

温病也会里结阳明，**可以用下法**，但下之宜**轻**不宜猛；判断能不能下、该不该苦泄，**全靠验舌**——有地之黄可下，光滑无地之黄大忌。

## 四、层次拆解

| 层次 | 原文关键句 | 讲的是什么 |
|------|-----------|-----------|
| ① 里结定位 | 在阳明胃与肠也 | 三焦不外解，最终结于胃肠 |
| ② 可否用下 | 不可以气血之分，谓其不可下也 | 破"温病忌下"之偏 |
| ③ 轻重之别 | 伤寒下之宜猛；此多湿热内抟，下之宜轻 | **核心差异：猛 vs 轻** |
| ④ 便溏意义 | 伤寒便溏＝邪尽；湿温便溏＝邪未尽 | 同一症状，相反判断 |
| ⑤ 苦泄指征 | 脘痛、痞胀＋舌黄或浊 | 病位近腹，可直折 |
| ⑥ 苦泄禁忌 | 白苔不燥、黄白相兼、灰白不渴 | 三种情况不可苦泄 |
| ⑦ 替代治法 | 宜从开泄，杏、蔻、橘、桔 | 轻苦微辛，流动气机 |
| ⑧ 有地无地 | 须要有地之黄，若光滑者……大忌 | **辨虚实的关键** |
| ⑨ 可下舌象 | 黄甚、沉香色、灰黄、老黄、中有断纹 | 五种舌，皆当下 |
| ⑩ 反面警戒 | 若未现此等舌，不宜用此等药 | 无舌象证据不可妄下 |

## 五、辨证眼目

**"有地之黄" vs "光滑之黄"**。同样是黄苔，有根者可苦泄攻下，光滑无根者是无形湿热兼中虚，一泻就坏。这一条比"黄苔主热"有用得多。

## 六、白话理解

温病也会便秘、腹胀、按之痛，跟伤寒的阳明腑实看着一样。但底子不同：伤寒是热把津液烤干，结成硬块，得猛药攻；温病多半是湿热搅在一起，黏滞不畅，猛攻会把脾阳打坏，所以要轻下、缓下。

最反直觉的是大便：伤寒拉稀说明邪已排干净，不能再下；湿温拉稀恰恰说明湿还没化尽，**必须拉到成形**才算无湿。同一个"溏"，一个代表结束，一个代表没完。

至于什么时候能苦泄（黄连、陷胸、泻心），叶氏给了硬指标：舌苔黄而浊、并且**有根**。如果苔是浮的、光滑的、或者白而不燥、灰白不渴，那多半不是实热，是湿、是寒、是虚，硬泄就把人泄坏了——这时候改用杏、蔻、橘、桔这类"轻苦微辛"的药，让气机转起来，湿自己会走。

## 七、我的理解 / 存疑

- **存疑**：「必大便硬，乃为无湿」——临床上湿温后期常见大便先硬后溏（脾虚），此时是否仍算"有湿"？叶氏此语似过于绝对，待查《温热经纬》章虚谷注及《温病条辨》中焦湿温诸条。
- **存疑**：所列可下舌象五种（黄甚／沉香色／灰黄／老黄／中有断纹），其中"中有断纹"机理为何？一般解作津伤燥裂，但亦有注家作"胃气将绝"，两说相去甚远。
- 「小承气汤，用槟榔、青皮、枳实、元明粉、生首乌等皆可」——此句像是把"小承气汤"与一组替代药并列，非小承气原方。底本断句可疑，标为存疑。
