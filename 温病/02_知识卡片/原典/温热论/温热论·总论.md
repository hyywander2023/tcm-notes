# 温热论·总论（编者概述）

> [!warning] 这一节不是叶天士原文
> 底本此节末句自陈「**兹重编分章论述如下**」，可知为后人重编时所加的导读，非叶氏本文。
> 读的时候要把它当"目录说明"，不能当条文引用。同理，全书十二章的章题（温病大纲、逆传入营……）也出自重编者之手。

## 一、原文（整理本）

> 温病是外感热病的一大类型。叶天士温热论是论述温病证治的名著，创立用卫分、气分、营分、血分四个层次作为辨证的根据，并指出温病的传变模式有顺传与逆传二种：顺传由卫而气而营而血，逐步传入；逆传由卫分直入营分。至于卫、气、营、血如何分辨，主要是根据温病的诊断特点，运用察舌、验齿以及辨斑、疹、白㾦，作为要点，然后结合证情，作出诊断，决定治法。全篇从原则到具体，有一套完整的理法方药，对临床实践起着指导作用。兹重编分章论述如下。

## 二、校注

- 「白㾦」：底本作「白 」，`㾦` 字整字脱漏，仅存空格。此为全书 45 处同类脱漏之一，整理本补字，不改文义。
- 「根据」两处：底本以「根据」代「依」（"作为辨证的根据""主要是根据温病的诊断特点"），系录入系统的批量替换痕迹，文义无误，整理本保留原样未动。

## 三、提要

全书的骨架就三句话：**辨证用卫气营血，传变分顺逆，诊断靠舌齿斑疹**。

## 四、层次拆解

| 要素 | 内容 |
|------|------|
| 辨证坐标 | 卫 → 气 → 营 → 血（四个层次） |
| 传变模式 | 顺传：卫→气→营→血，逐步深入 |
| | 逆传：卫分直入营分（跳越气分） |
| 诊断手段 | 察舌、验齿、辨斑疹、辨白㾦 |
| 落脚点 | 由诊断定治法，"一套完整的理法方药" |

## 五、辨证眼目

「**逆传由卫分直入营分**」——这七个字是温病区别于伤寒的关键。伤寒可以"一日太阳、二日阳明"按经传，温病却可能一步跨过气分，所以温病学家才要另立营分证治。

## 六、白话理解

伤寒是一条街一条街往里打，温病是可能翻墙直接进后院。翻墙那条路就叫"逆传心包"，所以上焦篇第一句必须是"首先犯肺，逆传心包"，提醒你防线可能被绕过。

## 七、我的理解 / 存疑

- **存疑**：本章说"逆传由卫分直入营分"，但第一章原文是"逆传**心包**"。营分与心包在叶氏体系里是否完全等同？教材多作"逆传心包即邪入营分"，但《温热经纬》王孟英按语对此有分辨，待与 [[温热经纬·卷三]] 对读后回填。
- 章题既是后人所加，引用时宜写"《温热论》第一章（通行编次）"，避免误作叶氏自题。
