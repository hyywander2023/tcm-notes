# 上焦纲领组（1–3 条）

## 一、原文（整理本）

### 第一条

> 温病者：有风温、有温热、有温疫、有温毒、有暑温、有湿温、有秋燥、有冬温、有温疟。

> [!note]- 吴鞠通自注（九种定义，节）
> 风温者，初春阳气始开，厥阴行令，风夹温也。温热者，春末夏初，阳气弛张，温盛为热也。温疫者，厉气流行，多兼秽浊，家家如是，若役使然也。温毒者，诸温夹毒，秽浊太甚也。暑温者，正夏之时，暑病之偏于热者也。湿温者，长夏初秋，湿中生热，即暑病之偏于湿者也。秋燥者，秋金燥烈之气也。冬温者，冬应寒而反温，阳不潜藏，民病温也。温疟者，阴气先伤，又因于暑，阳气独发也。

### 第二条

> 凡病温者，始于上焦，在手太阴。

### 第三条

> 太阴之为病，脉不缓不紧而动数，或两寸独大，尺肤热，头痛，微恶风寒，身热自汗，口渴，或不渴，而咳，午后热甚者，名曰温病。

**底本**：[[温病条辨·卷一·上焦篇#风温、温热、温疫、温毒、冬温]]

## 二、校注

- 「九条」：自注中"此九条，见于王叔和《伤寒例》中居多"，指九种温病之名，非九条条文。
- 「厉气」：即疠气、戾气，吴又可所谓"异气"。
- 「尺肤热」：前臂内侧（尺部）皮肤热，温病初起的客观体征之一。
- 底本「遵根据」当作「遵依」、「以为根据附」当作「依附」，属 `根据` 代 `依` 之录入痕迹。

## 三、提要

先**正名**（九种温病各有定义），再**定位**（始于上焦手太阴），最后**立提纲**（脉动数、尺肤热、口渴、咳、午后热甚）。

## 四、层次拆解

| 条 | 做的是什么 | 关键 |
|----|-----------|------|
| 1 | 分类 | 九种之名出于《伤寒例》，但吴氏给了自己的定义 |
| 2 | 定位 | 与伤寒"始足太阳"对举，温病"始手太阴" |
| 3 | 立提纲 | 与伤寒中风、伤寒对举，逐症辨异 |

**第三条的辨异逻辑**（自注）：

| 症 | 伤寒 | 温病 | 辨异点 |
|----|------|------|--------|
| 脉 | 缓（中风）/ 紧（伤寒） | **不缓不紧而动数** | 脉是第一位 |
| 头痛 | 循太阳经上至头项，项强 | 天气郁、火炎上 | 部位与性质不同 |
| 恶风寒 | 太阳属寒水主表 | 肺合皮毛亦主表 | **都有，不能靠这个分** |
| 自汗 | 风疏卫 | 皮毛开 | 都有 |
| 渴 | 无 | 火克金 | 温病有 |
| 咳 | 无 | 肺气郁 | 温病有 |
| 尺肤热 | 无 | 火反克水 | 温病有 |
| 午后热甚 | 无 | 浊邪归下、火旺时 | 温病有 |

> [!important] 这一段的方法论
> 吴氏不是列举"温病有什么症状"，而是**逐项排除与伤寒重合的部分**，只留下真正能分的四项：脉动数、渴、咳、尺肤热、午后热甚。这种"辨异"写法，是本书最值得学的地方。

## 五、辨证眼目

**"脉不缓不紧而动数"**。恶寒、自汗、头痛三项寒温皆有，靠不住；脉一动数，温病即定。

## 六、白话理解

第一条是"分类学"：温病不是一种病，是九种病的总称，各有发病时节与病因。吴氏特意给每一种下了短定义，等于先划清边界，免得后面混着讲。

第二条是"定位"：伤寒从皮毛进、从后背（太阳）开始；温病从口鼻进、从肺（太阴）开始。一上一下，两条路。

第三条是"验明正身"：症状列了一大串，但真正管用的是脉。因为头痛、怕冷、出汗这三样，伤寒也有，光看这些分不出来。加上"尺肤热"（摸前臂内侧发热）、"午后热甚"这两个客观体征，就把温病钉死了。

## 七、我的理解 / 存疑

- **存疑**：九种温病中"温热"与"风温"的界限，吴氏以时节分（初春／春末夏初），但临床上二者常连续过渡。这个分类是**教学分类**还是**病理分类**？待读卷四杂说"温病起手太阴论"。
- **存疑**：条 2 说"必从河间三焦定论"，把三焦辨证的源头归给刘完素。此说在学术史上是否站得住？刘河间主"六气皆从火化"，与三焦辨证未必是一回事。留待查证。
