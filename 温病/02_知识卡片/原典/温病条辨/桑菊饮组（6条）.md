# 桑菊饮组（6 条）

## 一、原文（整理本）

> 太阴风温，但咳，身不甚热，微渴者，辛凉轻剂桑菊饮主之。

> [!note]- 吴鞠通自注
> 咳，热伤肺络也。身不甚热，病不重也。渴而微，热不甚也。恐病轻药重，故另立轻剂方。

**底本**：[[温病条辨·卷一·上焦篇#风温、温热、温疫、温毒、冬温]]

## 二、校注

- 「但咳」：**只有咳嗽**是主症，这是本条的题眼。不是"咳嗽很重"。
- 「辛凉轻剂」：三级中的最轻一级，与银翘散（平剂）、白虎汤（重剂）对举。
- 底本「苦梗」即苦桔梗之省。

## 三、组成与用法（原文）

> 杏仁（二钱） 连翘（一钱五分） 薄荷（八分） 桑叶（二钱五分） 菊花（一钱） 苦梗（二钱） 甘草（八分） 苇根（二钱）
> 水二杯，煮取一杯，日二服。

**加减法（原文）**：

| 兼症 | 加减 |
|------|------|
| 二三日不解，气粗似喘，燥在气分 | 加石膏、知母 |
| 舌绛暮热，甚燥，邪初入营 | 加元参二钱、犀角一钱 |
| 在血分 | 去薄荷、苇根，加麦冬、细生地、玉竹、丹皮各二钱 |
| 肺热甚 | 加黄芩 |
| 渴 | 加花粉 |

## 四、提要

热伤肺络、**咳为主而热不重**，用辛凉轻剂。药量极轻（桑叶二钱五分、菊花一钱），是刻意为之——"恐病轻药重"。

## 五、层次拆解

| 原文 | 提示 |
|------|------|
| 但咳 | 主症在肺络 |
| 身不甚热 | 热不重，非气分 |
| 微渴 | 津伤尚浅 |
| 辛凉轻剂 | 药力与病位匹配 |

> [!important] 与银翘散的分界
> 不是"轻一点用桑菊、重一点用银翘"，而是**主症不同**：桑菊饮治"但咳"（肺络），银翘散治"但热不恶寒而渴"（卫表）。教材常讲成程度之分，与原文不合。

## 六、辨证眼目

**"但咳"两个字**。发热不高、口渴不重、就是咳——用桑菊饮。若热势已壮、四大俱备，那是白虎汤的事。

## 七、白话理解

温邪进了肺，最轻的表现就是咳。热不重（身不甚热）、津伤不深（微渴），此时用重药反而伤正，所以吴鞠通把药量压得很低：桑叶二钱五、菊花一钱，煎出来淡淡的。

桑叶、菊花是主角。吴氏自注讲得很文学：桑得箕星之精，箕好风，风气通于肝，故桑叶善平肝风；菊花晚成，能补金水二脏。这段话现代人读着玄，但意思清楚——**桑叶走肺络、菊花清上焦**，二药轻清上扬，正合"治上焦如羽"。

杏仁、桔梗一降一升，宣降肺气；连翘、薄荷、苇根清透余热。整张方没有一个重药，这就是"轻剂"的含义。

## 八、我的理解 / 存疑

- **存疑**：桑菊饮与银翘散的分界，我按原文理解为"主症之别"（咳 vs 热）。但临床常见咳与热并重，此时如何取舍？吴氏未言。依加减法看，桑菊饮可加石膏、知母（气分）、犀角、元参（营分），说明它是一张**可层层加深的底方**，未必只能用于轻证。
- **存疑**：方论中"桑得箕星之精"一套说理，属古代物象比类，现代无法验证。记录以存其说，不据此论药效。
