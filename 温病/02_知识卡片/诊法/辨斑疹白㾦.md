# 辨斑疹白㾦

> [!info] 三者不是一回事
> **斑**：点大、平铺皮肤之上（"点大而在皮肤之上"）
> **疹**：琐碎小粒、云头隐隐（"或云头隐隐，或琐碎小粒"）
> **白㾦**：白色小水疱，如水晶色（"小粒如水晶色"）
> 原文出处：[[温热论·第十章·辨斑疹]]、[[温热论·第十一章·辨白㾦]]。

## 一、斑与疹的分野

| | 斑 | 疹 |
|---|---|---|
| 形态 | 点大，平铺皮肤上 | 琐碎小粒，云头隐隐 |
| 分布 | 胸背两胁多见（须用纸捻照看） | 同 |
| 层次 | **属血者恒多** | **属气者不少** |
| 病位 | 胃 / 心包 | 肺 / 气分 |

> [!warning] 原文用的是"恒多""不少"
> 不是"斑属血、疹属气"的绝对划分，而是**倾向性判断**。引用时不可坐实。

## 二、斑的色泽与预后

| 色泽 | 主病 | 预后 |
|------|------|------|
| 红 | 胃热 | 顺 |
| 紫而点小 | 心包热 | 较重（病位深） |
| 点大而紫 | 胃中热 | 较重（病位浅但热盛） |
| 黑而光亮 | 热极，但气血犹充 | 虽属不治，依法治之**或有可救** |
| 黑而晦 | 热极而气血败 | **必死** |
| 黑而隐隐、四旁赤色 | 火郁内伏 | 大用清凉透发，**间有转红而可救** |

## 三、阴斑——最容易被误治的一种

| 表现 | 意义 |
|------|------|
| 淡红色 | 色不深 |
| 四肢清（凉） | 阳不达四末 |
| 口不甚渴 | 无实热 |
| 脉不洪数 | 非阳脉 |
| 面赤足冷 | 阴盛格阳于上 |
| 下利清谷 | 里寒 |

**治法：当温之。** 若按"斑色红属胃热"清热，则误。

## 四、顺逆

| 表现 | 判断 |
|------|------|
| 斑疹出而**神情清爽** | 外解里和（顺） |
| 斑疹出而**昏** | 正不胜邪而内陷，或胃津内涸（逆） |
| 宜见而不宜多见 | 透邪为顺，过多伤正 |

## 五、白㾦

| 形态 | 病机 | 治法 | 预后 |
|------|------|------|------|
| 小粒如水晶色 | 湿热伤肺，邪虽出而**气液枯** | 必得甘药补之 | 可 |
| 同上，但病未久延 | 湿郁卫分，汗出不彻 | 当理气分之邪（**不可补**） | 可 |
| 枯白如骨 | 气液竭 | — | **多凶** |

> [!important] 一亮一枯，治法相反
> 同样大小的白㾦：晶莹＝气液未伤，要**理气透邪**；枯白＝气液已竭，要**甘药补之**。补与透，看津液，不看白㾦本身。

## 六、三者的层次归属

| | 层次 | 一句话 |
|---|---|---|
| 疹 | 气分 | 邪从气分外透 |
| 斑 | 血分 | 热迫血溢，邪从血分外露 |
| 白㾦 | 卫分／气分 | 湿郁汗出不彻，津液化痰成疱 |

## 八、我的理解 / 存疑

- **存疑**：「黑而光亮」的光亮指斑面光泽还是斑周红晕？若指后者，就与"黑而隐隐四旁赤色"重复了；若指前者，则"光亮"是气血未败之象。两说待考。
- **存疑**：阴斑当温，与温病清热的总基调相反。这说明叶氏在"辨色"之上还有"辨外症"一层——**色是死的，症是活的**。这是全章方法论上最值得记的一句。
