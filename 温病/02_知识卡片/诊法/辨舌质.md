# 辨舌质

> [!info] 分工
> 本卡只收舌**质**（绛、紫、淡红）；舌**苔**（白、黄、黑）见 [[辨舌苔]]。
> 原文出处：[[温热论·第八章·察舌]]。

## 一、总纲

舌质看的是**人**，苔看的是**邪**。舌质由淡红→红→绛→紫，是热由气入营、由营入血、由血入瘀的一条直线。

| 舌质 | 层次 | 一句话 |
|------|------|--------|
| 淡红无色 | 胃津伤（虚） | 气无化液，禁寒凉 |
| 红 | 气分 | （叶氏未专论，散见各条） |
| 绛 | 营分 | 热传营，舌色必绛 |
| 紫 | 血分 | 热传营血，多挟宿瘀 |

## 二、绛舌（营分主舌）

| 兼象 | 主病 | 治法 |
|------|------|------|
| 绛色中兼黄白色 | 气分之邪未尽 | 泄卫透营，两和 |
| 纯绛鲜泽 | **包络受邪** | 犀角、鲜生地、连翘、郁金、石菖蒲 |
| 纯绛＋延之数日／素心虚有痰 | 里络闭 | 牛黄丸、至宝丹（恐昏厥为痉） |
| 绛而干燥 | 火邪劫营 | 凉血清血 |
| 绛而舌心干 | 心胃火燔 | 加黄连、石膏 |
| 舌心独绛而干 | 胃热灼心营 | 清胃方加清心之品 |
| 舌尖独绛而干 | 心火上炎 | 导赤散（泻其腑） |
| 舌心干、四边色红、中心黄白 | **非血分**，上焦气热烁津 | 凉膈散，**慎勿用血药** |
| 望之若干、扪之原有津液 | 津亏湿热熏蒸，将成浊痰蒙闭心包 | 防蒙闭 |
| 上有粘腻似苔非苔 | 中挟秽浊 | 急加芳香逐之 |
| 抵齿难伸 | 痰阻舌根，有内风 | — |
| 绛而光亮 | **胃阴亡** | 急用甘凉濡润 |
| 有碎点黄白 | 将生疳 | — |
| 大红点 | 热毒乘心 | 黄连、金汁 |
| 虽绛而不鲜、干枯而痿 | **肾阴涸** | 阿胶、鸡子黄、地黄、天冬（缓则无救） |

> [!warning] 最容易错的一条
> 「舌心干，四边色红，中心或黄或白」看着像营血，实为**上焦气热烁津**，当用凉膈散。若误投血药（生地、阿胶之属），滋腻留邪，热反不退。

## 三、紫舌（血分主舌）

| 形态 | 主病 | 治法 |
|------|------|------|
| 紫而暗，扪之潮湿 | 素有瘀伤宿血＋热 | 琥珀、丹参、桃仁、丹皮（**加散血之品**） |
| 紫而肿大 | 酒毒冲心 | — |
| 紫而干晦 | 肾肝色泛 | **难治** |

紫而暗的关键在"扪之潮湿"：干燥的紫是热灼，潮湿的紫是瘀。不加散血，瘀热相抟，会变如狂发狂。

## 四、淡红舌

> 舌若淡红无色，或干而色不荣者，乃是胃津伤而气无化液也。当用炙甘草汤，不可用寒凉药。

这是全章唯一的**虚证舌**，也是唯一用温补方的舌。温病书里出现炙甘草汤，正是叶氏"不执一家"的证明。

## 五、看舌质三问（我的归纳，非原文）

1. **鲜泽不鲜泽**——鲜泽为邪盛，光亮为阴亡，干枯为阴涸。
2. **干润与扪之有无津**——目视干而手扪有津，是湿热熏蒸，不是单纯津伤。
3. **部位**——舌心（胃/心）、舌尖（心）、四边（气分）、满舌（营血）。

## 七、我的理解 / 存疑

- **存疑**：绛舌十六种兼象，教材多简化成"绛而干＝营热伤阴、绛而润＝营热挟湿"两类，与叶氏原文的细致程度相差很远。做临床时原文更可用，做考试时教材更省事——两者都要留。
- **存疑**：「紫而干晦，肾肝色泛」——"肾肝色泛"究竟指何色？五行中肾黑、肝青，紫而晦近于青黑，或即此意。属推测。
