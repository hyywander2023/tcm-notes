# 知识库使用说明（内经版）

> 与 [[伤寒/00_知识库入口/知识库使用说明|伤寒版]]、[[温病/00_知识库入口/知识库使用说明|温病版]] 是同一套目录规则的第三个副本。
> 同名不同内容，双链时请注明"内经版"。

## 一、每个目录放什么

| 目录 | 放什么 |
|------|--------|
| 00_知识库入口 | 总览、书目清单、本说明、校勘总表 |
| 01_原始资料 | 转码底本与整理本，**不改内容** |
| 02_知识卡片 | 一篇一卡、一概念一卡（待建） |
| 03_方法模板 | 卡片模板（待建） |
| 04_任务项目 | 正在做的研读项目 |
| 05_复盘反馈 | 阶段性复盘 |
| 99_归档 | 弃用但保留 |

`01_原始资料` 下分三层：`经文/`、`注家/`、`现代著作/`。整理本统一放 `_整理本/`，与底本同名加「（整理本）」。

## 二、文件命名

```
{简称}·{篇名}.md          例：素问·上古天真论篇第一.md
{简称}·第03部.md          聚合本，例：宣明论方·第03部.md
{简称}·卷首.md            序跋凡例合并
```

**为什么带书名前缀**：Obsidian 按文件名解析双链。全库「序」出现了 4 次，「手太阴肺经」「禁针穴歌」在针灸书里重复几十次。不带前缀必然撞名。

简称对照：素问、素问遗篇、素问集注、灵枢集注、太素、内经评文、内经博议、内经知要、素问校义、玄珠密语、原病式、保命集、宣明论方、十二经脉秘。

## 三、front matter 字段

```yaml
---
类型: 原始资料          # 原始资料 | 整理本
书名: 黄帝内经素问
简称: 素问
卷: 卷第一              # 底本有卷次标记才有；取自原文 <目录>卷N
别名: 阴阳离合论篇第六    # 底本篇名与通行本不合时才加
篇: 上古天真论篇第一      # 聚合本改用「聚合单元: 第03部」
作者: 王冰次注
朝代: 唐
成书: 公元762年
来源: 中华医典数字化文本（437-黄帝内经素问）
备注: 版本说明
---
```

整理本另有 `整理:` 与 `底本:` 两个字段，指向重排规则与底本路径。

> [!tip] 按卷检索
> `卷:` 字段来自原文的 `<目录>卷第一` 标记（语义是"下一篇所属卷"），24 卷全部还原，与王冰本次序吻合。
> 在 Obsidian 搜索框输入 `["卷": "卷第七"]` 或直接用属性筛选，就能按卷取篇。

## 四、底本与整理本怎么用

| | 底本 | 整理本 |
|---|---|---|
| 用途 | **核对、引文** | **日常阅读** |
| 特点 | 保留定宽硬换行、`∶`、缺字空格 | 接回换行、按句末重分段 |
| 字数 | 与原文本一字不差 | 一字不差，只改版式 |

**引文一律以底本为准**。整理本只重排了版面，但机器分段难免有断错的地方，万一引文出错，底本是唯一凭据。

两者互链：每份底本顶部有 `[[XX（整理本）]]`，每份整理本顶部有 `[[XX]]`。

## 五、双链写法

| 场景 | 写法 |
|------|------|
| 引某篇 | `[[素问·举痛论篇第三十九]]` |
| 引聚合本某节 | `[[宣明论方·第03部#某篇名]]` |
| 用通行篇名引（底本有讹字） | `[[阴阳离合论篇第六]]`（靠别名解析，跳到 `素问·阴阴离合论篇第六`） |
| 跨库引针灸 | `[[甲乙经·卷首]]`、`[[针灸大成·第03部]]` |
| 跨库引伤寒温病 | `[[457-伤寒论]]`、`[[温病条辨·卷一·上焦篇]]` |
| 指向外部路径 | 纯文本，不加双链 |

> [!warning] 同名文件
> 内经、针灸、伤寒、温病四库都有 `卷首`，文件名都带书名前缀所以不冲突；
> 但 `知识库使用说明` 四份同名，双链时务必写全路径或注明版本。

## 六、插图缺失

转码文本里有 584 处中华医典的图片占位（`\r图名\pX.bmp\r`），**图片文件没有随文本提供**。

已就地转成可读标注：

```
［原书插图：仰人周身总穴图　原件 pG-G1.bmp，图片未随文本提供］
```

内经库涉及 21 处（主要在内经知要的卦图、素问集注的运气图、太素的九宫八风图）。看到这个标注，就知道原书此处有图、图未入库，**不要当成正文引用**。

## 七、哪些操作要先问

沿用伤寒版规则，以下必须先确认再做：

1. **覆盖** 已有文件内容
2. **移动** 文件到别处
3. **删除** 任何文件或目录
4. **外发** 内容到库外

可以直接做：新建文件、末尾追加、读取。

另加一条本库特有的：

5. **改底本正文**——一律不改。发现讹字写进 [[内经文本校勘总表]]，不改原文。
