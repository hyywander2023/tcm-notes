# 内经知识库 · 总览

> 收《黄帝内经》白文、历代注家、以及一部现代体证著作，共 14 部、675 文件。
> 与伤寒、温病、针灸三库同处一个 vault（`D:\中医`），可双链互通。总入口见 [[总库地图]]。

## ⚠️ 先读这一条：本库没有《灵枢》白文

桌面原始资料里**只有《素问》白文**（`437-黄帝内经素问`，王冰次注本），**没有《灵枢》白文**。
《灵枢》全文目前唯一的来源是 [[灵枢集注·卷首|张隐庵《灵枢集注》]]——它是**集注体**，经文与注文混排，引文时若不辨，容易把张注当经文。

因此：

| 引用场景 | 用哪个 |
|---|---|
| 引《素问》原文 | `素问·XX篇`（白文，可靠） |
| 引《灵枢》原文 | `灵枢集注·XX第X`，**须自己辨认哪段是经、哪段是注**；或查 [[甲乙经·卷首\|《甲乙经》]]（保留大量灵枢古传文字） |
| 引注家观点 | 对应注本，注明作者 |

## 三、建库五条原则

1. **原文一字不改**。底本存原貌（含硬换行、`∶`、缺字空格）；整理本只重排版式，不增删一字。异文写进 [[内经文本校勘总表]]。
2. **经、注、论分家**。引用时必须说清是经文还是某家注。`素问·XX` 是经，`素问集注·XX` 是张志聪的读法，两者不能混着引。
3. **现代著作降级处理**。祝华英书中"十二经脉双向运行"是个人修证结论，与《灵枢》原文不是同一层证据，引用需明示性质。
4. **篇为最小单位**。内经的双链粒度是篇（`[[素问·举痛论篇第三十九]]`），不是段。跨篇引用就链篇名。
5. **不确定就写"存疑"**。中华医典文本有录入讹误，能确定为瑕疵的才改，疑有异文一律存疑。

## 六、知识层：素问、灵枢两个大分支

`02_知识卡片` 不是按书分目录，而是**按知识点组织**，再向素问、灵枢两支分叉：

```
02_知识卡片/
├── 素问总览.md         ← 分支一入口：81 篇按 24 卷 + 专论篇 + 知识点索引
├── 灵枢总览.md         ← 分支二入口：81 篇按篇序 + 专论篇 + 知识点索引
├── 太素类编总览.md      ← 分支三入口：太素 183 篇按十九类重编，附与素问/灵枢逐篇对应
├── 病证/  28 张         ← 痹 痿 咳 疟 厥 胀 积 消瘅 水肿 热病 …
├── 概念/  26 张         ← 阴阳 五行 五脏 六腑 营卫 三焦 津液 九针 标本 …
└── 太素/  19 张         ← 摄生 阴阳 人合 脏腑 经脉 输穴 营卫气 身度 诊候 证候 设方 九针 补泻 伤寒 寒热 邪论 风 气论 杂病
```

**第三个分支是《太素》，性质与前两支不同**：它不是与素问、灵枢并列的另一种经典，而是这两部书本身的类编全注本。分出来单列，是为了让「换一套编次看同一批文字」这件事在库里看得见——十九类就是杨上善对医理结构的判断。详见 [[太素类编总览]]。

每张卡内部**固定按两支分开列**，这是本层的基本体例：

| 节 | 内容 |
|---|---|
| 一、素问 | 该知识点在素问出现的全部篇，带卷次、处数，专论篇置顶；**每篇后挂集注对读链接** |
| 二、灵枢 | 该知识点在灵枢出现的全部篇（集注本），专论篇置顶；**每篇后挂内经评文链接** |
| 三、代表原文 | 自动挑定义句（「痹者」「谓之痹」「为痹也」），素问 2 条 + 灵枢 1 条 |
| 四、注家互证 | 太素、内经知要、内经博议、甲乙经的篇数 |
| 五、相关知识点 | 同篇共现，自动生成，提示阅读路径 |
| 六、按语 | **留空** |

**两个分支的差异不是硬凑的，是数据本身的分工**：

- 素问偏「论」——痹论、痿论、咳论、疟论、厥论、气厥论、刺腰痛、通评虚实论，一篇一病；
- 灵枢偏「经」——营卫生会、营气、卫气（三篇）、九针（两篇）、经脉、经筋、气街、海论，形质与刺法之学。

证据很硬：**「营卫」在素问白文 0 见、灵枢 29 篇；「经筋」素问 0 见**。这类词只会出现在灵枢那一支。

> [!tip] 怎么用
> 想读某个病，从 `病证/痹.md` 进，一次拿到素问 25 篇 + 灵枢 28 篇 + 每篇的集注/评文对读入口，再顺着「相关知识点」跳到厥、痿、寒热。
> 想通读，从 [[素问总览]] 或 [[灵枢总览]] 进，按卷次或篇序走。

> [!warning] 卡片是索引卡，不是注解卡
> 卡片只做摘录与索引，不拆「定义／病机／治法」字段——素问、灵枢、注家体例不一，硬拆必错。
> 全部由 `~/.workbuddy/scripts/neijing2cards.py` 生成，改格式改脚本重跑，**别手改这 56 个文件**。

### 太素层怎么用

太素与素问、灵枢是**同一批文字的两套编次**，所以要对照着读，不是另读一本书：

1. 读《素问》某篇时，到 [[太素类编总览]] 第三节查表：这一篇被太素拆到了哪几类。
2. 从十九类看杨上善的分类判断。比如「身度」把骨度、肠度、脉度收在一处，是认为形质度量自成一套——这在原有篇序里看不出来。
3. 每篇太素整理本末尾有「太素类编出处」区块，直接跳出所出的素问/灵枢篇，并附句数分量。
4. 三方对读：太素、甲乙经同为类编本，同一段经文的异文，萧延平「平按」已逐字校出。

> [!important] 出处不是我推的
> 底本（萧延平校注本）在每篇篇首有「平按」一段，逐条交代「此篇自某至某，见《灵枢》卷第几第几《某篇》」。
> 脚本解析这段声明、按篇序定篇，再用逐句文本比对核验分量；两者的出入如实标为「文重合推定」。
> 全库 480 条出处边中，468 条为平按明载。
