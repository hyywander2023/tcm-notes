# 四逆散

## 一、原文（一字不改）

> **《伤寒论·辨少阴病脉证并治》第 318 条**
> 少阴病，四逆，其人或咳、或悸、或小便不利、或腹中痛、或泄利下重者，四逆散主之。方十七。

## 二、组成

| 药 | 原文用量 | 备注 |
|----|---------|------|
| 甘草 | 炙 | 各十分 |
| 枳实 | 破，水渍，炙干 | 各十分 |
| 柴胡 | | 各十分 |
| 芍药 | | 各十分 |

四味药等分，作散剂。柴胡、枳实主气，芍药、甘草主血——**气血并调**。

## 三、用法（原文加减（节录））**

> 上四味，各十分，捣筛，白饮和服方寸匕，日三服。咳者，加五味子、干姜各五分，并主下利；悸者，加桂枝五分；小便不利者，加茯苓五分；腹中痛者，加附子一枚，炮令坼；泄利下重者，先以水五升，煮薤白三升，煮取三升，去滓，以散三方寸匕，内汤中，煮取一升半，分温再服。

白话：白饮（米汤）调服散剂。五个或然症各有加减；泄利下重者以薤白汤煮散服。

## 四、主治与辨证要点

- **主治**：**气郁致厥**——阳气内郁不达四末而手足逆冷，非阳虚阴盛之寒厥。
- **辨证眼目**：列在少阴篇但**不是少阴病**——四逆程度轻（不过腕踝），兼见气郁诸症（腹中痛、泄利下重），与四逆汤类的沉微欲绝脉截然不同。
- 「或然症」皆气机郁滞波及上下所致。

## 五、白话理解

这个人手脚冰凉，看着像虚寒，其实底子是**气被郁住了**：肝气不舒，阳气憋在里头出不去，四肢自然凉。就像暖气管总阀被关了，锅炉没坏。

所以不用温热药，而用柴胡疏解郁结、枳实破滞气、芍药甘草柔缓筋脉——气机一转，阳气布散，四逆自愈。**同为「四逆」，一实一虚、一疏一回阳**，是厥证鉴别诊断的关键样本。

## 六、我的理解 / 存疑

- **本条列于少阴篇是「类证鉴别」笔法**（借少阴之名，与四逆汤对照），已成共识，但历代仍有争论，可入观点卡。
- 后世由此衍化出柴胡疏肝散、逍遥散一整套疏肝理气法门——四逆散是「气郁」治法的源头，地位极高。
- 「或咳或悸」的加减皆与小青龙汤、真武汤的或然症加减格式相同，可对照学习仲景或然症处理规律。
- 泄利下重（里急后重）用薤白通阳导滞，是「后重」病机属气滞的经典依据。
