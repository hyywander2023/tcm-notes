# 茯苓桂枝白术甘草汤（苓桂术甘汤）

## 一、原文（一字不改）

> **《伤寒论·辨太阳病脉证并治中》第 67 条**
> 伤寒，若吐、若下后，心下逆满、气上冲胸、起则头眩、脉沉紧，发汗则动经，身为振振摇者，茯苓桂枝白术甘草汤主之。方三十。

## 二、组成

| 药 | 原文用量 | 备注 |
|----|---------|------|
| 茯苓 | 四两 | 君药，利水宁心 |
| 桂枝 | 三两（去皮） | 通阳降冲 |
| 白术 | 二两 | 健脾燥湿 |
| 甘草 | 二两（炙） | |

四味药，「苓桂剂」家族的核心。

## 三、用法（原文）

> 上四味，以水六升，煮取三升，去滓，分温三服。

## 四、主治与辨证要点

- **主治**：中阳不足、水饮上逆——「心下逆满、气上冲胸、起则头眩、脉沉紧」。
- **辨证眼目**：
  - **起则头眩**：体位性眩晕，起身时水饮随之上冲——水饮证的特异性症状；
  - **发汗则动经，身为振振摇**：误汗后水饮泛溢经脉、身体震颤——**自带禁忌与误治后果预测**的条文。
- 与 [[真武汤]]（82 条）对照：==🟡彼振振欲擗地属肾阳虚水泛（更重一层），此为中焦阳虚饮停。==

## 五、白话理解

吐下之后脾胃的阳气伤了，运不动水，水饮停在心下：一躺一起就晕（起身时水往上涌），气往上冲胸口，脉沉紧。

茯苓把水渗利下去，桂枝把阳气通开并平降冲逆，白术健运脾土从根上断水的来源，甘草和中。**治水三步：利其标（苓）、降其冲（桂）、固其本（术）**。

「痰饮病当以温药和之」（金匮）的代表方，后世一切「苓桂剂」（苓桂甘枣、苓桂味甘等）皆由此衍生。

## 六、我的理解 / 存疑

- 「发汗则动经」是仲景**预判误治**的笔法：条文同时给出现证、当下治法和误治后果——三层信息在一条内，值得作为「条文结构」的样本。
- 与 [[茯苓桂枝甘草大枣汤]]（65 条，脐下悸欲作奔豚）仅一味之差（白术 vs 大枣），病位一在中焦（心下逆满）、一在下焦（脐下悸）——一味药换病位，方法卡极好素材。
- 存疑：「脉沉紧」在饮证与寒实证中的双重含义（紧主水饮抟聚），与 67 条被脉的读法，注家有异。
- 现代治耳源性眩晕、高血压眩晕属水饮者沿用广，「起则头眩」是取用点。
