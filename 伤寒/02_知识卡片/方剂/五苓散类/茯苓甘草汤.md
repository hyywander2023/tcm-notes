# 茯苓甘草汤

## 一、原文（一字不改）

> **《伤寒论·辨太阳病脉证并治中》第 73 条**
> 伤寒，汗出而渴者，五苓散主之；不渴者，茯苓甘草汤主之。方三十六。

> **《辨厥阴病脉证并治》第 356 条**
> 伤寒厥而心下悸，宜先治水，当服茯苓甘草汤，却治其厥，不尔，水渍入胃，必作利也。

## 二、组成

| 药 | 原文用量 | 备注 |
|----|---------|------|
| 茯苓 | 二两 | |
| 桂枝 | 二两（去皮） | |
| 甘草 | 一两（炙） | |
| 生姜 | 三两（切） | 温散水气 |

四味药 = 苓桂术甘汤**去白术、加生姜**。

## 三、用法（原文）

> 上四味，以水四升，煮取二升，去滓，分温三服。

## 四、主治与辨证要点

- **主治**：水停心下（胃）之轻证——**不渴**的水饮。
- **辨证眼目**：
  - 第 73 条是对偶鉴别句：汗出而**渴**→五苓散（水停下焦、气化不行）；汗出**不渴**→茯苓甘草汤（水停心下、津液尚能上承）；
  - 第 356 条：厥而心下悸，**先治水后治厥**——治有先后次序的示范。
- 「水渍入胃，必作利也」：不先治水的后果预测。

## 五、白话理解

水停在胃脘这一层，还没影响到下焦气化，所以不渴；水气凌心就心下悸；阳气被阻就手足凉。

茯苓渗水，桂枝通阳，生姜把胃里的水寒散开。方子小、药量轻——**轻证轻剂**。356 条的精髓在次序：厥虽急，根子是水，先利水，阳气通了厥自回；不先治水，水渗进肠子就变成下利。

## 六、我的理解 / 存疑

- 第 73 条「渴与不渴」作为五苓散/茯苓甘草汤的分水岭，是「一症定方」的极简鉴别——但临床水饮可动态变化，渴之有无须动态观察，不宜机械化。
- 「先治水却治厥」与「先表后里」「先里后表」共同构成仲景**治序（治疗次序）**思想，值得做方法卡汇总。
- 存疑：356 条「厥而心下悸」的病机归胃阳虚水停 vs 心阳虚水泛——胃说为主流（因云水渍入胃），心说亦有据（悸属心），可入观点卡。
- 本方与苓桂术甘汤、苓桂甘枣汤构成「苓桂剂三兄弟」（术/枣/姜一味之差），是经方加减变化的教科书。
