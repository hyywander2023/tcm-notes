# 抵当丸

## 一、原文（一字不改）

> **《伤寒论·辨太阳病脉证并治中》第 126 条**
> 伤寒有热，少腹满，应小便不利，今反利者，为有血也，当下之，不可余药，宜抵当丸，方六十六。

## 二、组成

| 药 | 原文用量 | 备注 |
|----|---------|------|
| 水蛭 | 二十个（熬） | 比汤剂减十个 |
| 虻虫 | 二十个（熬，去翅足） | |
| 桃仁 | 二十五个（去皮尖） | |
| 大黄 | 三两 | |

四味，捣分四丸。

## 三、用法（原文）

> 上四味，捣分四丸。以水一升，煮一丸，取七合服之。晬时，当下血；若不下者，更服。

白话：一次煮服一丸。「**晬时**」（一昼夜）后下血；不下再服。

## 四、主治与辨证要点

- **主治**：蓄血重证之**缓者**——「伤寒有热，少腹满」。
- **辨证眼目**：
  - 少腹**满**（胀满）而非硬满急结——结深而不急；
  - **应小便不利，今反利者，为有血也**——原文用排除法自证病在血分；
  - 「不可余药」：不能用别的（轻）药敷衍，须直攻其血。

## 五、白话理解

瘀血结在下焦，与 [[抵当汤]] 证同源但**病势缓**——不那么急迫。峻药做成丸剂、分四次用、以一昼夜为观察周期：**药量减、节奏慢，但打击目标不变**（仍是水蛭虻虫搜血）。

「不可余药」四字很有性格：病重如此，绕弯子的方子顶不了事。

## 六、我的理解 / 存疑

- 「晬时当下血」——以**下血**作为疗效判断指标（不是大便），与桃核承气「当微利」形成对照：两方都以「下」为度，下物不同。
- 汤丸之别的时间维度：汤剂「不下更服」（小时级），丸剂「晬时不下更服」（昼夜级）——同一病机的急缓两档，与大小陷胸汤丸的结构完全平行，**「汤急丸缓」规律的四组例证之一**（陷胸、抵当、理中、枳实栀子）。
- 存疑：「不可余药」三句的句读与释义——「不可用其余（轻缓）之药」为通行解，亦有校作「不可余（残余）药力」者，两读文义有别。
