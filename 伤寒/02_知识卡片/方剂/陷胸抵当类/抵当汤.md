# 抵当汤

## 一、原文（一字不改）

> **《伤寒论·辨太阳病脉证并治中》第 124 条**
> 太阳病，六七日表证仍在，脉微而沉，反不结胸；其人发狂者，以热在下焦，少腹当硬满，小便自利者，下血乃愈。所以然者，以太阳随经，瘀热在里故也。抵当汤主之。方六十四。

## 二、组成

| 药 | 原文用量 | 备注 |
|----|---------|------|
| 水蛭 | 三十个（熬） | 破血逐瘀，虫类搜剔 |
| 虻虫 | 三十个（去翅足，熬） | |
| 桃仁 | 二十个（去皮尖） | |
| 大黄 | 三两（酒洗） | |

四味药，**攻逐瘀血的最峻方**——虫药直入血络搜剔死血。

## 三、用法（原文）

> 上四味，以水五升，煮取三升，去滓，温服一升，不下更服。

白话：不下（不泻下/不下血）再服一次。

## 四、主治与辨证要点

- **主治**：太阳蓄血重证——瘀血与热结于下焦。
- **辨证眼目**：
  - **发狂**（桃核承气仅「如狂」）；
  - 少腹**硬满**（不 mere 急结）；
  - **小便自利**——排除蓄水（血分病，膀胱气化无碍）；
  - 脉微而沉（血结于里，非气分）。
- 「太阳随经，瘀热在里」：表邪循经入里与血相结的病机自注。

## 五、白话理解

热邪钻进血分，和瘀血死死胶结在下焦，结得又深又老——植物药（桃仁大黄）够不着了，必须用**动物药**：水蛭、虻虫都是吸血之物，「以其嗜血，故破血」，能钻进血络深处把陈年老瘀搜出来。

药力之峻，「抵当」之名或谓「直抵血结当攻之处」。蓄血证至此为极——桃核承气（新瘀轻证）→ 抵当丸（重而缓）→ 抵当汤（重而急）。

## 六、我的理解 / 存疑

- **虫类药的引入**是本方的理论标志：叶天士「久病入络」用虫药搜剔之说即滥觞于此。
- 三级蓄血鉴别（如狂/发狂、急结/硬满、血自下/不下）与两级处方（桃核承气/抵当）——方法卡「蓄血证谱系」。
- 存疑：「脉微而沉」与 119 条（通行本）「脉微而沉」的「微」是否作「凝滞不流」解而非虚象？虚证见此脉而用峻攻于理不合——脉义训诂公案。
- 水蛭虻虫的现代药理（抗凝）与安全性边界——沿用发展层面的重要议题，当代以抵当汤治脑血管病、子宫内膜异位等属瘀重者多有报道。
