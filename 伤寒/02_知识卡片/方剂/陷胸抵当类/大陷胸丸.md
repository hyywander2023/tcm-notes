# 大陷胸丸

## 一、原文（一字不改）

> **《伤寒论·辨太阳病脉证并治下》第 131 条（节录）**
> 结胸者，项亦强，如柔痉状，下之则和，宜大陷胸丸。方一。

**校注**：底本「如柔 状」脱「痉」字（通行本作「如柔痉状」）；柔痉＝发热汗出而项背强直之证名。原文未改。

## 二、组成

| 药 | 原文用量 | 备注 |
|----|---------|------|
| 大黄 | 半斤 | |
| 葶苈子 | 半升（熬） | 泻肺利水 |
| 芒硝 | 半升 | |
| 杏仁 | 半升（去皮尖，熬黑） | |

四味，捣筛，取**弹丸大一枚**，另捣**甘遂末一钱匕、白蜜二合**同煎服。

## 三、用法（原文）

> 上四味，捣筛二味，内杏仁、芒硝，合研如脂，和散。取如弹丸一枚，别捣甘遂末一钱匕、白蜜二合、水二升，煮取一升，温顿服之，一宿乃下；如不下，更服，取下为效。禁如药法。

白话：制丸如弹丸大，每次一枚，与甘遂末、白蜜同煮，顿服。**一宿乃下**——起效慢（丸者缓也）；不下再服。

## 四、主治与辨证要点

- **主治**：结胸之**高位者**——水热结于胸膈偏上，波及项部。
- **辨证眼目**：「项亦强，如柔痉状」——结胸本位在心下，此型结聚位置高，牵连项背强直如柔痉（有汗），「下之则和」。
- 与大陷胸汤之别：汤证心下石硬痛不可近（急重），丸证项强位高（**缓攻**）——同一病机，位置与缓急定剂型。

## 五、白话理解

水热结的位置偏高，顶得脖颈都僵了。猛攻怕伤正（高位近肺），峻药缓图：做成丸剂，加白蜜的甘缓牵制甘遂大黄的暴烈，让药力**缓缓地、持续地**把高位的水热泻下去——「一宿乃下」就是缓攻的时间刻度。

**汤与丸的分野**在此方展现得最清楚：药味几乎同（汤方大黄芒硝甘遂，丸方加葶苈杏仁引药上行入肺），剂型一改，药力走向和节奏全变。

## 六、我的理解 / 存疑

- 葶苈、杏仁的加入被普遍解释为「引药上行、泻肺中水气」——从大陷胸汤的三味到丸剂四味的加法，体现**病位高低决定引经药**的思路。
- 「如柔痉状」提示与痉病鉴别：彼为筋病（津亏），此为结胸牵连（实邪）——「但下其结，项自强愈」。
- 存疑：白蜜甘缓与甘遂峻下同用，是否存在「互相牵制太过」的问题？临床用量比例的经验传承值得查考。
- 丸剂的「弹丸大一枚」的剂量换算与甘遂一钱匕的比例——剂型学考据点。
