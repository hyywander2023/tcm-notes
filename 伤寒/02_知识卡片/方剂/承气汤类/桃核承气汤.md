# 桃核承气汤（桃仁承气汤）

## 一、原文（一字不改）

> **《伤寒论·辨太阳病脉证并治中》第 106 条**
> 太阳病不解，热结膀胱，其人如狂，少腹急结者，血自下，下者愈。其外不解者，尚未可攻，当先解其外；外解已，但少腹急结者，乃可攻之，宜桃核承气汤。方五十六。（后云，解外宜桂枝汤。）

**校注**：底本「但少腹急结者」前有「血自下，下者愈。其外不解者……」等句序文，与通行本一致；括注为底本原有。

## 二、组成

| 药 | 原文用量 | 备注 |
|----|---------|------|
| 桃仁 | 五十个（去皮尖） | 破血逐瘀 |
| 大黄 | 四两 | |
| 桂枝 | 二两（去皮） | 通阳行血 |
| 甘草 | 二两（炙） | |
| 芒硝 | 二两 | |

五味药 = 调胃承气汤去甘草之重？非——实为**调胃承气 + 桃仁、桂枝**：借承气之力下瘀血。

## 三、用法（原文）

> 上五味，以水七升，煮取二升半，去滓，内芒硝，更上火微沸，下火。先食温服五合，日三服，当微利。

白话：芒硝溶化后离火，**饭前（先食）温服**，每日三次，以**微利**为度——泻下不是目的，逐瘀才是。

## 四、主治与辨证要点

- **主治**：太阳蓄血轻证——「热结膀胱……如狂，少腹急结」。
- **辨证眼目**：
  - **如狂**（而非发狂）：瘀热上扰心神尚轻；
  - **少腹急结**：血结下焦，按之拘急硬痛；
  - **小便自利**（第 125 条对举）：血分病而非水停。
- 治疗次序：外不解先解外，「外解已……乃可攻之」。

## 五、白话理解

表邪化热顺着太阳经深入下焦，与血纠结在一起：瘀血堵在少腹（少腹急结），热与瘀血上冲扰心（如狂）。好在这瘀结还嫩——有时血自己下（月经、便血）就好了。

药也顺着这个思路：桃仁化瘀，桂枝推动血脉，大黄芒硝把热和瘀从大便导出去。**借肠道排瘀血**，所以「当微利」即止。

## 六、我的理解 / 存疑

- 「热结膀胱」的「膀胱」指下焦血分部位而非膀胱腑（因小便利），是经典病位训诂点。
- 与 [[抵当汤]]（第 124 条）对看：桃核承气治**新瘀轻证**（如狂、少腹急结、血可自下），抵当汤治**久瘀重证**（发狂、少腹硬满、脉微而沉）——蓄血证轻重的两级。
- 「先食温服」：空腹服药利于药力直抵下焦，服法细节提示病位。
- 桂枝在此不在解表而在通阳助血行——同一味药在不同配伍中的身份转换，值得建方法卡。
