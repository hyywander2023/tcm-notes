# 大承气汤

## 一、原文（一字不改）

> **《伤寒论·辨阳明病脉证并治》第 208 条**
> 阳明病，脉迟，虽汗出不恶寒者，其身必重，短气，腹满而喘，有潮热者，此外欲解，可攻里也。手足濈然汗出者，此大便已硬也，大承气汤主之；若汗多，微发热恶寒者，外未解也；（一法与桂枝汤）其热不潮，未可与承气汤；若腹大满不通者，可与小承气汤，微和胃气，勿令至大泄下。

**校注**：底本「手足然汗出」脱「濈」字（通行本作「濈然汗出」）；「（一作汗出）」类夹注为底本原存校语。原文未改。

## 二、组成

| 药 | 原文用量 | 备注 |
|----|---------|------|
| 大黄 | 四两（酒洗） | |
| 厚朴 | 半斤（炙，去皮） | 行气除满，**用量最大** |
| 枳实 | 五枚（炙） | 破结消痞 |
| 芒硝 | 三合 | 咸寒软坚 |

四味药。**先煮枳朴，后下大黄，再溶芒硝**——煎法次序是本方的灵魂。

## 三、用法（原文）

> 上四味，以水一斗，先煮二物，取五升，去滓；内大黄，更煮取二升，去滓；内芒硝，更上微火一两沸，分温再服。得下，余勿服。

白话：枳实厚朴先煮，大黄后下（取其攻下之力），芒硝最后溶化。「**得下，余勿服**」——泻下来就停药。

## 四、主治与辨证要点

- **主治**：阳明腑实重证——痞、满、燥、实俱备。
- **辨证眼目**：潮热、手足濈然汗出、大便硬、腹满而喘、脉迟有力（迟为气机壅滞，非虚寒）；甚则谵语、目中不了了（252 条）、独语如见鬼状（212 条）。
- **三道防线**（本条原文自带）：外未解不可攻；热不潮不可与承气；腹大满但未至燥坚用小承气。

## 五、白话理解

阳明燥屎结得又硬又满，气机完全堵死：肚子胀满、喘、出汗只出手心脚心（里热蒸迫）、说胡话。这时只有猛攻一条路——枳实厚朴把堵住的气机推开，大黄芒硝把燥屎润化冲开。

「大承气」的「大」在气势更在**分寸**：煎法上大黄后下保持冲劲，服法上「得下余勿服」防止过剂伤正。**攻邪方里处处见护正**，这是本方的深层结构。

## 六、我的理解 / 存疑

- 「脉迟」出现在承气证中是经典鉴别点：迟而有力（气机壅滞）vs 迟而无力（虚寒），单凭脉象可误判，须合参腹满潮热。
- 厥阴篇 320-322 条「少阴三急下」：口燥咽干、腹胀不大便等用大承气急下存阴——**少阴篇里出现攻下法**是理解「急下存阴」的枢纽，值得单独做方法卡。
- 存疑：252 条「目中不了了，睛不和，无表里证」的急下指征，是津液将竭的信号，注家解释分歧在「无表里证」三字。
- 与 [[小承气汤]]、[[调胃承气汤]] 组成「三承气」鉴别体系：药味增减与煎法次序同时变化，是经方剂量-煎法-证候对应的最佳标本。
