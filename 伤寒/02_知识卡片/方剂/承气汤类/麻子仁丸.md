# 麻子仁丸（脾约丸）

## 一、原文（一字不改）

> **《伤寒论·辨阳明病脉证并治》第 247 条**
> 趺阳脉浮而涩，浮则胃气强，涩则小便数；浮涩相搏，大便则硬，其脾为约，麻子仁丸主之。方三十一。

## 二、组成

| 药 | 原文用量 | 备注 |
|----|---------|------|
| 麻子仁 | 二升 | 润肠通便，君药 |
| 芍药 | 半斤 | |
| 枳实 | 半斤（炙） | |
| 大黄 | 一斤（去皮） | |
| 厚朴 | 一尺（炙，去皮） | |
| 杏仁 | 一升（去皮尖，熬，别作脂） | |

六味药 = 小承气汤（枳朴大黄）+ 麻仁、杏仁、芍药（润燥益阴）。**蜜丸**缓服。

## 三、用法（原文）

> 上六味，蜜和丸如梧桐子大。饮服十丸，日三服，渐加，以知为度。

白话：炼蜜为丸，每次十丸起服，逐渐加量，**以大便通为度**——丸者缓也。

## 四、主治与辨证要点

- **主治**：脾约证——胃强脾弱，津液偏渗而大便硬。
- **辨证眼目**：趺阳脉（足背动脉，候脾胃）**浮而涩**：浮=胃气亢盛，涩=脾阴不足；小便数（津液从前阴走，后阴失润）而**不更衣十日无所苦**（第 244 条佐证：没有腹满谵语等腑实重症）。
- 与承气汤证区别：**无潮热、无谵语、无腹满硬痛**——只是习惯性便硬。

## 五、白话理解

胃火偏旺，脾的津液却被「约」住，只往膀胱走（小便多），肠子里干得大便结硬。但这不是急证实证，是慢性功能失调——所以不用汤剂猛攻，而是做丸药慢慢润：麻仁杏仁含油脂润肠，芍药养阴，小量枳朴大黄推动，蜂蜜滋润。

「脾约」二字：脾被胃热约束，津液不能四布。这是后世「润下」法的源头，治习惯性便秘、老年便秘、产后便秘的常用底方。

## 六、我的理解 / 存疑

- 「其脾为约」的病机解释（胃强脾弱 vs 脾阴虚津亏）历代有出入，与临床用方选择直接相关，值得做观点卡。
- 「不更衣十日无所苦」与急下诸条对照：判断是否攻下的核心不在便硬的天数，而在有无浊气上扰与腑气壅滞之象。
- 渐加以知为度：丸剂「增量到见效」的服药法，与汤剂「中病即止」互为镜像。
