# 黄连汤

## 一、原文（一字不改）

> **《伤寒论·辨太阳病脉证并治下》第 173 条**
> 伤寒，胸中有热，胃中有邪气，腹中痛，欲呕吐者，黄连汤主之。方三十五。

## 二、组成

| 药 | 原文用量 | 备注 |
|----|---------|------|
| 黄连 | 三两 | 清上热，君药 |
| 甘草 | 三两（炙） | |
| 干姜 | 三两 | 温下寒 |
| 桂枝 | 三两（去皮） | 通阳散寒 |
| 人参 | 二两 | |
| 半夏 | 半升（洗） | 降逆止呕 |
| 大枣 | 十二枚（擘） | |

七味药 = 半夏泻心汤**去黄芩、加桂枝**，黄连增量——上清下温的格局更纯粹。

## 三、用法（原文）

> 上七味，以水一斗，煮取六升；去滓，温服。昼三夜二。疑非仲景方。

白话：不分再煎。**昼三夜二**——白天服三次、夜里服两次的频服法（全书记载的独特服法）。方后「疑非仲景方」为宋臣校语存疑标记。

## 四、主治与辨证要点

- **主治**：上热下寒、寒热分居——「胸中有热，胃中有邪气，腹中痛，欲呕吐」。
- **辨证眼目**：热在上（胸中烦热欲呕），寒在下（腹中痛），**上下格拒而寒热不杂于心下**——这是与泻心汤类「寒热互结于中」的根本区别。

## 五、白话理解

热浮在上面、寒沉在下面，中间的升降枢纽失灵了：胸中有热就想吐，肚子有寒就疼痛。黄连把上面的热清掉，干姜桂枝把下面的寒温开，半夏降逆、人参甘草大枣把中轴扶正——**让热自降、寒自升，恢复对流**。

「昼三夜二」的服法也贴病机：证势缠绵，须日夜持续给药维持药力。

## 六、我的理解 / 存疑

- **方后「疑非仲景方」**——宋臣对此方与 [[麻黄升麻汤]]（第 357 条）、[[芍药甘草附子汤]]（第 68 条）皆有疑，属原书自带的三处存疑标记，值得做成一张「宋臣疑方」方法卡。
- 与 [[半夏泻心汤]] 鉴别：同为寒热并用，彼是**寒热互结**（心下痞），此是**寒热分居**（上热欲呕、下寒腹痛）——「结」与「拒（格）」之辨。
- 桂枝在此温通上下，非解表——又一味药「换岗」的例子（对照桃核承气汤中桂枝通血脉）。
- 后世以本方治慢性胃肠病上下寒热错杂者，与泻心汤类同源分流。
