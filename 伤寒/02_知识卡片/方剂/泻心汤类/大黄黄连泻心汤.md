# 大黄黄连泻心汤

## 一、原文（一字不改）

> **《伤寒论·辨太阳病脉证并治下》第 154 条**
> 心下痞，按之濡，其脉关上浮者，大黄黄连泻心汤主之。方十七。

## 二、组成

| 药 | 原文用量 | 备注 |
|----|---------|------|
| 大黄 | 二两 | |
| 黄连 | 一两 | |

二味药。

**校注**：林亿等看详：「诸本皆二味；又后附子泻心汤用大黄、黄连、黄芩、附子，恐是前方中亦有黄芩，后但加附子也。」——是否原有黄芩，为版本公案。

## 三、用法（原文）

> 上二味，以麻沸汤二升渍之，须臾绞去滓。分温再服。

白话：**麻沸汤（滚开水）浸泡**片刻，绞汁服，**不煎煮**——取气不取味，泻热而不攻下。

## 四、主治与辨证要点

- **主治**：无形邪热壅聚心下之热痞——「心下痞，按之濡，其脉关上浮」。
- **辨证眼目**：
  - 按之**濡**（软）：无有形之结，与结胸硬痛对照；
  - 关上浮：热聚中焦，脉应之；
  - 与 [[半夏泻心汤]] 证鉴别：彼寒热错杂（有呕利等），此**纯为热痞**。

## 五、白话理解

热气聚在胃脘，痞塞不通，但按下去是软的——没有实质的结块，只是一团无形的热。既然没有实物可攻，煎法就成了关键：大黄黄连只用开水泡一泡就喝，==🟡**只取药物的清轻之气去清热，不用它厚重的味道去泻下**==。

这是全书中「**煎法改变药效方向**」最著名的一例：同样的药，煮久了攻下，泡一下清热。

## 六、我的理解 / 存疑

- 存疑（版本）：原方是否含黄芩（林亿校语）——《金匮要略》泻心汤为三味，宋本《伤寒论》二味，两系统并存。
- 「麻沸汤渍之」的意义：尤在泾等注家反复申说，是「取其气、薄其味」的示范，可入观点卡。
- 第 164 条「伤寒大下后复发汗，心下痞……攻痞，大黄黄连泻心汤」先表后里的次序，与 164 条桂枝解表互参。
- 后世以此泡服法治上部出血（吐血衄血，取釜底抽薪之意）属沿用发展。
