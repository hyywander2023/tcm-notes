# 甘草泻心汤

## 一、原文（一字不改）

> **《伤寒论·辨太阳病脉证并治下》第 158 条**
> 伤寒中风，医反下之，其人下利，日数十行，谷不化，腹中雷鸣，心下痞硬而满，干呕心烦不得安。医见心下痞，谓病不尽，复下之，其痞益甚。此非结热，但以胃中虚，客气上逆，故使硬也。甘草泻心汤主之。方二十一。

## 二、组成

| 药 | 原文用量 | 备注 |
|----|---------|------|
| 甘草 | 四两（炙） | **君药，加倍**，补虚安中 |
| 黄芩 | 三两 | |
| 干姜 | 三两 | |
| 半夏 | 半升（洗） | |
| 大枣 | 十二枚（擘） | |
| 黄连 | 一两 | |

六味药 = 半夏泻心汤**甘草加倍为君**（底本方中**无人参**）。

**校注**：林亿等谨按：「……其方必各有人参，今甘草泻心中无者，脱落之也。又按千金并外台秘要……皆有人参，知脱落无疑。」——原文无人参系脱文，照录。

## 三、用法（原文）

> 上六味，以水一斗，煮取六升，去滓；再煎取三升。温服一升，日三服。

白话：去滓再煎同前法。

## 四、主治与辨证要点

- **主治**：胃虚益甚之痞——一误再下后，客气上逆。
- **辨证眼目**：下利日数十行、**谷不化**（完谷不化，胃虚无权腐熟）、腹中雷鸣、干呕心烦不得安；「**此非结热，但以胃中虚，客气上逆**」——原文自带病机自注。
- 与前两泻心鉴别：半夏泻心（呕）、生姜泻心（水气食臭），甘草泻心（**虚最重**，以下利谷不化为标志）。

## 五、白话理解

被反复误下后，胃气彻底虚了：一天拉几十次，吃啥拉啥，肚子擂鼓，还干呕心烦睡不着。这时心下的痞硬不是热结，是**虚得关不住门**，外来的邪气（客气）趁机往上顶。

所以重用炙甘草四两补中缓急，坐镇中焦，仍是清上温下的架子，但重心全在「补虚以运痞」。误治两次、证还在变，方也跟着变——这条是「动态辨证」的最佳教材。

## 六、我的理解 / 存疑

- **人参脱落问题**：林亿校语明确（千金、外台皆有人参），今通行多补人参；本卡原文照录无人参，校注说明——底本文字与校勘结论分开呈现。
- 「客气上逆」概念：非体内之热，是**外邪乘虚入里上逆**，与结热之痞的本质区别，原文自注极清晰。
- 三泻心（半夏/生姜/甘草）+ 两泻心（大黄黄连/附子）合为「五泻心」体系，是同底方加减的极则，方法卡必做。
