# 泻心汤类鉴别

> 来源：依据本库 [[半夏泻心汤]]、[[生姜泻心汤]]、[[甘草泻心汤]]、[[大黄黄连泻心汤]]、[[附子泻心汤]]、[[黄连汤]] 六张方剂卡整理（AI 整理，2026-10-19）。原文引用均照卡片底本，一字不改。

## 一、一句话定位

- **五泻心**＝一个骨架的五个变奏：三泻心（半夏、生姜、甘草）治**寒热互结之痞**，大黄黄连、附子泻心治**热痞**（一方兼阳虚）。
- **黄连汤**不算泻心汤，但同属「上热下寒、辛开苦降」家族，是最容易和泻心汤混的一个——**差别在「结」与「分居」**。

## 三、七个鉴别点

### 鉴别点 1：痞与结胸——满而不痛 vs 硬痛

第 149 条原文自带鉴别，是全书最干净的一处分水岭：

> 若心下满而硬痛者，此为结胸也，大陷胸汤主之；但满而不痛者，此为痞，柴胡不中与之，宜半夏泻心汤。

- **硬痛**（按之石硬、拒按）→ 结胸，有形水热互结，当下（[[大陷胸汤]]）。
- **但满不痛 / 按之濡** → 痞，==🟡无形气机壅塞==，当辛开苦降。
- 小陷胸汤（138 条）是「正在心下，按之则痛」——痛在按后、程度轻，介于两者之间，属痰热互结，别于大陷胸的「从心下至少腹硬满」。
- **抓手**：痞证病人自己说「堵」，但压下去不喊疼；结胸是你手一碰他就躲。

### 鉴别点 2：三泻心互辨——呕 / 食臭水气 / 虚甚谷不化

三方同底，差在两味药和三个症状，是「同体别名」的最佳教材（第 157 条方后注原文即称「同体别名耳」）。

| 鉴别项  | 半夏泻心汤      | 生姜泻心汤            | 甘草泻心汤                   |
| ---- | ---------- | ---------------- | ----------------------- |
| 来路   | 柴胡证误下（149） | 汗出解之后（157）       | 误下后复下（158）              |
| 主症   | **呕**而肠鸣   | **干噫食臭**、腹中雷鸣、下利 | **下利日数十行、谷不化**、干呕、心烦不得安 |
| 病机重心 | 寒热互结，胃气不和  | 水气食滞偏重（胁下有水气）    | **胃虚最重**，客气上逆           |
| 药物微调 | 干姜三两、半夏半升  | **生姜四两**，干姜减为一两  | **炙甘草四两**，余同            |
| 一句话  | 痞而==🟡呕==  | 痞而==🟡嗳腐肠鸣==     | 痞而==🟡完谷不化==            |

**为什么这样加减，才是这三方的真义**：
- 半夏冠名治呕，故呕显者用半夏泻心；
- 生姜四两散水气、降逆气，干姜减量防助燥——水食停滞、嗳出馊味时，病位偏「水」不偏「寒」；
- 炙甘草四两补中缓急，因为下利几十次、完谷不化，中气已虚到「关不住门」，补虚优先于清温。

> 注意：**三方并非三个病，而是一个病在不同伤正途径下的三个阶段/三种兼夹**。第 158 条「==🟡医见心下痞，谓病不尽，复下之，其痞益甚==」正是动态辨证的范例。

肚子痛不一定要用下法让它拉出来，也有可能是心下痞

### 鉴别点 3：寒热错杂痞 vs 纯热痞——有无呕利

| | 三泻心（寒热错杂） | 大黄黄连泻心汤（热痞） |
|---|---|---|
| 病性 | 寒热并见 | **纯热**，无寒 |
| 症状 | 呕、肠鸣、下利、食臭等 | 仅心下痞，无呕利 |
| 腹诊 | 痞硬（多言「痞硬」） | **按之濡**（软） |
| 脉 | 不限 | **关上浮** |
| 用药 | 芩连 + 姜夏 + 参草枣 | 仅大黄、黄连 |

**抓手**：问两件事——**吐不吐、拉不拉**。有呕利肠鸣，走三泻心；只是堵、按着软、嘴上火，走大黄黄连。

### 鉴别点 4：热痞 vs 热痞兼阳虚——一症之差，一药之变

第 154 与 155 条只差「复恶寒、汗出」四字，方中只多一枚附子，但**煎法完全不同**：

> 心下痞，按之濡，其脉关上浮者，大黄黄连泻心汤主之。（154）
> 心下痞，而复恶寒、汗出者，附子泻心汤主之。（155）

- 恶寒汗出若属**表证**，则犯「痞而表未解不可攻」之诫（第 164 条先表后里），此时当先解表；
- 若属**阳虚卫外不固**（无发热、脉不浮），才是附子泻心汤证；
- 附子泻心汤的做法是**三黄麻沸汤渍、附子别煮取汁**——寒药取气、热药取味，各行其道，是全书「寒热分煎」的孤例。
- **抓手**：痞而怕冷出汗，先分表里；无表证才加附子。

### 鉴别点 5：寒热互结 vs 寒热分居——泻心汤 vs 黄连汤

这是最容易混、也最值得记的一条。

| | 泻心汤类 | 黄连汤（173） |
|---|---------|--------------|
| 寒热位置 | 寒热**互结于心下**（搅在一起） | 热在**胸中**、寒在**胃中（腹）**，上下**分居** |
| 主症 | **心下痞**（堵） | **腹中痛、欲呕吐**（痛 + 吐） |
| 有无痞 | 以痞为核心 | 原文**不言痞** |
| 药物 | 黄芩 + 黄连 + 干姜 + 半夏 | **去黄芩、加桂枝**，黄连增至三两 |
| 服法 | 去滓再煎 | 昼三夜二（日夜频服） |

**一句话**：泻心汤治「**结**」，黄连汤治「**格**」——寒热各占一处、互不相容，故用桂枝通阳、去黄芩之守中。黄连汤方后宋臣注「疑非仲景方」，属原书三处存疑标记之一（另见 [[麻黄升麻汤]]、[[芍药甘草附子汤]]）。

### 鉴别点 6：痞与相邻诸证的边界

| 易混证 | 关键鉴别 | 主方 |
|--------|----------|------|
| 柴胡证 | 149 条明言「柴胡不中与之」——已无往来寒热、胸胁苦满，病全入里成痞 | [[小柴胡汤]] |
| 结胸 | 硬痛 vs 但满不痛 | [[大陷胸汤]] / [[小陷胸汤]] |
| 寒格 | 「食入口即吐」为寒格特征，吐在入口即出，与泻心之干呕不同 | [[干姜黄芩黄连人参汤]] |
| 蓄血 / 阳明腑实 | 有燥屎、潮热、谵语或如狂，非但痞 | [[大承气汤]] / [[桃核承气汤]] |

### 鉴别点 7：胀满怎么分流——从「肚子胀」这个主诉入门

临床上病人不会说「我心下痞」，只会说「肚子胀」。听到「胀」先别急着套痞，有三处要拆：

**① 部位：痞定位在「心下」，不是泛称的「肚子」。**

心下＝胃脘、剑突下那一块。脐周、大腹、少腹的胀满各有归属：大腹满多属太阴脾虚或阳明腑实，少腹满要考虑蓄血、蓄水。**胀在哪儿，决定往哪条路上走。**

**② 「没有寒热」要分两层，混起来最容易误判。**

- **全身寒热**（发热、恶寒）：热痞本来就可以完全没有。第 154 条只给三个指标——`心下痞`、`按之濡`、`其脉关上浮`，一个字没提发热恶寒。所以「不发热不怕冷」不是排热的理由。
- **局部热象**：热痞的「热」靠口苦、心烦、舌红、苔黄、尿黄、关上浮来确认。这些都没有，「热痞」二字就悬空。

**③ 泻心汤的「寒热错杂」不是体温，是上下症状并存。**

==🟡上见呕、口苦、心烦（热），下见肠鸣、下利、腹冷（寒）==——同时存在，才叫寒热错杂。判断泻心汤证，问的不是「有没有发烧」，而是「上面有没有热象、下面有没有寒象」。

| 情况           | 按诊    | 关键兼症            | 归属                           |
| ------------ | ----- | --------------- | ---------------------------- |
| 心下满、不痛、按之软   | **濡** | 无呕利，口苦舌红、关上浮    | **热痞** → 大黄黄连泻心汤             |
| 心下痞硬、不痛      | 痞硬    | 呕 / 干噫食臭 / 下利肠鸣 | 寒热错杂痞 → 三泻心                  |
| 胀满喜按、食少乏力    | 软而无力  | 无呕利，脉弱，食后胀甚     | 虚人胀满 → [[厚朴生姜半夏甘草人参汤]]（66 条） |
| 胀满、呕吐、自利、口不渴 | 软     | 脉沉迟，畏寒          | 中焦虚寒 → [[理中丸]]               |
| 腹满痛、拒按、大便不通  | **硬** | 潮热、谵语、无矢气       | 阳明腑实 → 承气类                   |
| 胀而小便不利、口渴    | 软     | 渴欲饮水、水入则吐       | 蓄水 → [[五苓散]]                 |

**最短的判断办法：三个动作，不用一上来就想方**

1. **按一下心下**——软（濡）还是硬？痛不痛？这一下把痞、结胸、腑实分掉大半。
2. **问呕、问大便**——呕不呕、拉不拉、肠鸣不肠鸣？有呕利肠鸣，才往三泻心走。
3. **看舌和关脉**——舌红苔黄、关上浮，才叫热痞；舌淡苔白、脉弱，那不是热，别套大黄黄连。

> ==🟡结论：心下胀、按之软、不痛，已成痞的形态；但若既无局部热象、也无呕利肠鸣，它更可能是气滞或虚胀，不宜套任何一张泻心汤。==「无寒热」在这里不是支持痞的证据，只是**没提供信息**。

## 四、辨证路径（照着问）

1. **心下堵不堵？** 不堵 → 不属泻心汤类。
2. **按之痛不痛？** 硬痛拒按 → 结胸（大陷胸）；按之则痛、程度轻 → 小陷胸；**但满不痛/按之濡** → 痞，继续。
3. **吐不吐、拉不拉？**
   - 无呕无利、关上浮 → **大黄黄连泻心汤**（纯热痞）。
   - 兼恶寒汗出、无表证 → **附子泻心汤**（热痞兼阳虚）。
   - 有呕利肠鸣 → 三泻心，看下一层。
4. **主症落在哪？**
   - 呕为主 → **半夏泻心汤**。
   - 干噫食臭、腹中雷鸣、胁下有水气 → **生姜泻心汤**。
   - 下利日数十行、完谷不化、干呕心烦 → **甘草泻心汤**。
5. **是「痞」还是「痛 + 吐」？** 腹中痛、欲呕吐、原文无痞 → **黄连汤**（寒热分居）。

## 五、我的理解 / 存疑

- **「泻心」之「心」是心下（胃脘）**，非心臟；「泻」泻的是寒热错杂之邪，不是泻心火。这一点在半夏泻心汤卡已说明，此处再申。
- **五个泻心汤的骨架其实是「半夏泻心汤」一方的加减**，而第 157 条方后注又自承生姜泻心汤「本云理中人参黄芩汤，去桂枝、术，加黄连」——说明这个「骨架」本身也是层累形成的，不是一次设计出来的。这是研究经方源流的一手材料，值得单独建卡。
- **甘草泻心汤无人参**是林亿校语明确的脱文（《千金》《外台》皆有人参），底本照录、校注说明；临床上通行补人参。
- **大黄黄连泻心汤是否原有黄芩**：林亿看详「恐是前方中亦有黄芩，后但加附子也」，《金匮》泻心汤为三味——版本公案，未定。
- **煎法是鉴别的一部分**，不只是操作细节：三泻心的「去滓再煎」使寒热药性和合；大黄黄连的「麻沸汤渍」取气薄味；附子泻心的「分煎」使寒热各行其道。同一组药，煎法一变，作用方向就变——这条可以做一张独立的方法卡。
- 待补：**五泻心与《金匮》泻心汤（大黄、黄连、黄芩）的关系**，以及后世「半夏泻心汤治慢性胃炎」的循证材料，本库暂缺，标待建。
