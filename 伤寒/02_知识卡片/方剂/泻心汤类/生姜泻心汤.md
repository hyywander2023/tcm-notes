# 生姜泻心汤

## 一、原文（一字不改）

> **《伤寒论·辨太阳病脉证并治下》第 157 条**
> 伤寒汗出解之后，胃中不和，心下痞硬，干噫食臭，胁下有水气，腹中雷鸣下利者，生姜泻心汤主之。方二十。

## 二、组成

| 药 | 原文用量 | 备注 |
|----|---------|------|
| 生姜 | 四两（切） | **君药，量最重**，散水和胃 |
| 甘草 | 三两（炙） | |
| 人参 | 三两 | |
| 干姜 | 一两 | |
| 黄芩 | 三两 | |
| 半夏 | 半升（洗） | |
| 黄连 | 一两 | |
| 大枣 | 十二枚（擘） | |

八味药 = 半夏泻心汤**加生姜至四两**（干姜减为一两）。

## 三、用法（原文）

> 上八味，以水一斗，煮取六升，去滓，再煎取三升。温服一升，日三服。（附子泻心汤，本云加附子，半夏泻心汤，甘草泻心汤，同体别名耳。生姜泻心汤，本云理中人参黄芩汤，去桂枝、术，加黄连，并泻肝法。）

白话：去滓再煎。方后注极重要：指出几个泻心汤「**同体别名**」的家族关系，并保存了生姜泻心汤的另一来源（理中人参黄芩汤加减）。

## 四、主治与辨证要点

- **主治**：水饮食滞痞——汗解后胃气未复，水气食滞互结。
- **辨证眼目**：三大特征症——**干噫（嗳）食臭**（食物馊腐之气上泛）、**腹中雷鸣**（肠鸣亢进）、**下利**（水谷不别）+「胁下有水气」。
- 与半夏泻心汤证鉴别：彼以呕为主（半夏冠名治呕逆），此以**水气食臭肠鸣**为主（生姜冠名散水消滞）。

## 五、白话理解

病好了以后胃没养回来，吃进去的东西不消化，加上有水气停在胁下：打嗝都是食物馊味，肚子里咕噜咕噜响，还拉稀。

生姜加到四两当君药——辛散水气、健胃消食；干姜减量，温中即可不必助燥。其余照半夏泻心汤的架构：清上温下补中，把错杂的局面重新理顺。

## 六、我的理解 / 存疑

- 方后注「本云理中人参黄芩汤，去桂枝、术，加黄连」——古经方的**层累形成**痕迹，是研究经方源流的一手材料，值得单独摘出建卡片。
- 「干噫食臭」常被作为辨消化不良的特异性症状，与后世「伤食」概念衔接。
- 汗解后成痞（本条）与下后成痞（149/158）对照：伤正途径不同，痞的兼夹（水气/寒热/虚甚）不同。
