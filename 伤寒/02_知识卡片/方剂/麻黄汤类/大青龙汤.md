# 大青龙汤

## 一、原文（一字不改）

> **《伤寒论·辨太阳病脉证并治中》第 38 条**
> 太阳中风，脉浮紧、发热、恶寒、身疼痛、不汗出而烦躁者，大青龙汤主之；若脉微弱，汗出恶风者，不可服之。服之则厥逆、筋惕肉瞤，此为逆也。大青龙汤方。方八。

> **第 39 条**
> 伤寒，脉浮缓，身不疼，但重，乍有轻时，无少阴证者，大青龙汤发之。方九。（用前第八方。）

**校注**：底本第 38 条「筋惕肉」后脱一「瞤」字（通行本作「筋惕肉瞤」），原文未改。

## 二、组成

| 药 | 原文用量 | 备注 |
|----|---------|------|
| 麻黄 | 六两（去节） | **全书麻黄用量之最**，二倍于麻黄汤 |
| 桂枝 | 二两（去皮） | |
| 甘草 | 二两（炙） | |
| 杏仁 | 四十枚（去皮尖） | |
| 生姜 | 三两（切） | |
| 大枣 | 十枚（擘） | |
| 石膏 | 如鸡子大（碎） | 清里热 |

七味药 = 麻黄汤 + 石膏、生姜、大枣。表寒闭得最紧，里热已生烦躁，所以一边重用麻黄开表，一边用石膏清里。

## 三、用法（原文）

> 上七味，以水九升，先煮麻黄，减二升，去上沫，内诸药，煮取三升，去滓，温服一升，取微似汗。汗出多者，温粉粉之。一服汗者，停后服；若复服，汗多亡阳，遂（一作逆）虚，恶风、烦躁、不得眠也。

白话：仍是取**微汗**。汗出太多用温粉外扑止汗；**中病即止，一服汗出就停**——再服会汗多亡阳，出现怕风、烦躁、失眠。这是全书中煎服法警示最重的一条。

## 四、主治与辨证要点

- **主治**：表寒里热俱盛——「不汗出而烦躁」。
- **辨证眼目**：烦躁是里热标志，与麻黄汤（无烦）鉴别；表证（身疼痛、不汗出）仍在，与白虎汤（纯里热）鉴别。
- **禁忌写得极重**：脉微弱、汗出恶风者不可服——误服则厥逆、筋惕肉瞤（虚人发汗致阳气外脱、肌肉跳动）。
- 第 39 条从另一面立论：脉浮缓、身重而非身痛，只要「无少阴证」（排除了阴证），仍可用大青龙「发之」。

## 五、白话理解

麻黄汤证再往前一步：寒把表闭得死死的，体内的热散不出去，越积越多，人开始**烦躁**。所以这方是“边开门边灭火”：六两麻黄猛开门，一块鸡子大的石膏同时清里热，姜枣草护住中气防止猛药伤正。

原文反复强调“得汗即止、不可复服”——因为发汗力太猛，虚人误服会出大问题。它展示的是中医“中病即止”的用药哲学。

## 六、我的理解 / 存疑

- **两段著名矛盾，是注家千年公案**：第 38 条说「太阳中风，脉浮紧」，第 39 条说「伤寒，脉浮缓」——风/伤、紧/缓恰好互换了。多认为是仲景“风寒互举、脉有对举”的行文法，实指同一病机（表闭里热），但历代争论极多，**这是对照 [[472-张卿子伤寒论]] 最优先要看的条目之一**。
- 存疑：「烦躁」究竟是里热扰心，还是《内经》“阴气少而阳气胜”之义？大青龙烦躁与茯苓四逆汤（第 69 条）烦躁、吴茱萸汤烦躁的鉴别是关键。
- 存疑：石膏「如鸡子大」折合今量多少？鸡子大小古今不一，与白虎汤的一斤如何换算？
- 与 [[桂枝二越婢一汤]]（第 27 条）对看：同为表寒里热，彼为轻剂，此为峻剂。
