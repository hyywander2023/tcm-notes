# 麻黄附子甘草汤

## 一、原文（一字不改）

> **《伤寒论·辨少阴病脉证并治》第 302 条**
> 少阴病，得之二三日，麻黄附子甘草汤微发汗。以二三日无证，故微发汗也。方二。

**校注**：「无证」通行本或作「无（诸）证候」解，亦有校作「无里证」者，义指未出现吐利厥逆等少阴里证。原文照录，两读并存。

## 二、组成

| 药 | 原文用量 | 备注 |
|----|---------|------|
| 麻黄 | 二两（去节） | |
| 甘草 | 二两（炙） | 易细辛之位，取其缓和 |
| 附子 | 一枚（炮，去皮，破八片） | |

三味药 = [[麻黄细辛附子汤]] **去细辛、加甘草**。只换一味药，整个方子的“烈度”就降了一档。

## 三、用法（原文）

> 上三味，以水七升，先煮麻黄一两沸，去上沫：内诸药，煮取三升，去滓，温服一升，日三服。

白话：先煮麻黄一两沸去沫，日三服。注意煎水量比麻黄细辛附子汤（一斗）少，取其轻煎。

## 四、主治与辨证要点

- **主治**：少阴兼表证得之二三日、**无里证**者——温经微发汗。
- **辨证眼目**：「微发汗」三字是题眼——少阴阳虚，只能微微透达，不可峻汗。
- 与第 301 条对看：彼为「始得之」（病初，邪气尚盛，用细辛通内外）；此为「得之二三日」（邪势渐减、正气亦渐耗，用甘草守中缓图）。

## 五、白话理解

还是那个阳虚人感冒的病，但已经过了两三天：表邪没那么凶了，人也没出现拉肚子、四肢冷这些少阴重症。这时候不需要细辛那种“里外猛串”的药，换成甘草，让麻黄和附子慢慢来、轻轻发点汗就行。

一句话：**同一个病机的两档火力**——301 条是“急版本”，302 条是“缓版本”。仲景按病程深浅调整药力浓度，这两条合读最能看出经方的剂量思维。

## 六、我的理解 / 存疑

- 「以二三日无证，故微发汗也」是全条的解释性自注——仲景原文自带“为什么”，这种条文要重点收集，它们是理解组方逻辑的钥匙。
- 存疑：「无证」若读作“无里证”，则微发汗的理由充分；若读作“无（明显）证候”，则第 302 条本身就无从起病判断，文义反而吃紧。此字之争涉及版本源流，留待核对注本。
- 后世以此方加减治阳虚水肿（甘草助留水，水肿者常去之），是“沿用发展”，与原文用法已有距离。
