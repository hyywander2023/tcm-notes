# 麻黄连轺赤小豆汤

## 一、原文（一字不改）

> **《伤寒论·辨阳明病脉证并治》第 262 条**
> 伤寒瘀热在里，身必黄，麻黄连轺赤小豆汤主之。方四十四。

**校注**：「连轺」，原文自注「连翘根是」。今临床通行用连翘，用根者极少，属古今用药之变，原文照录。

## 二、组成

| 药 | 原文用量 | 备注 |
|----|---------|------|
| 麻黄 | 二两（去节） | |
| 连轺 | 二两（连翘根） | 清热利湿 |
| 杏仁 | 四十个（去皮尖） | |
| 赤小豆 | 一升 | 利湿退黄 |
| 大枣 | 十二枚（擘） | |
| 生梓白皮 | 一升（切） | 今多以桑白皮代 |
| 生姜 | 二两（切） | |
| 甘草 | 二两（炙） | |

八味药。结构上是“麻黄汤变体 + 利湿退黄药”：麻黄、杏仁、姜、枣、草宣散表湿，连轺、赤小豆、生梓白皮清利里湿。

## 三、用法（原文）

> 上八味，以潦水一斗，先煮麻黄再沸，去上沫，内诸药，煮取三升，去滓。分温三服，半日服尽。

白话：用**潦水**（地面流动的雨水积水）煎药，麻黄先煮两沸去沫，半日内分三次服完。

## 四、主治与辨证要点

- **主治**：湿热发黄之偏表者——「瘀热在里，身必黄」。
- **辨证眼目**：本条是阳明发黄诸条中**兼表**的一型：黄的同时当有表证未罢（无汗、小便不利之湿郁），故仍从表分消湿热。
- 阳明发黄三方对看：[[茵陈蒿汤]]（第 236 条，里实热重）、栀子柏皮汤（第 261 条，热重于湿）、本方（兼表，湿重于热）。

## 五、白话理解

发黄（黄疸）的病机是湿热互结、郁蒸发黄。这一型的特点是：湿热虽在里，但**表的通道还没打通**——毛孔不开、小便不畅，湿没有出路。所以方里保留少量麻黄开表，配赤小豆、连轺、梓白皮从小便把湿引出去，表里两条路同时分消，湿去热孤，黄自然退。

用潦水、用连翘根这类细节，都带着汉代“取象”用药的痕迹。

## 六、我的理解 / 存疑

- 存疑：「瘀热在里」却用麻黄解表，历代多解为“表里分消”，但本条原文并未明言表证，表证的证据是从方药“以方测证”反推的——这是《伤寒论》研究的一个经典方法示例，也是争议来源。
- 存疑：生梓白皮今已难寻，通行以桑白皮代之，药性出入（梓白皮偏寒、桑白皮泻肺利水）是否影响配伍本意？
- 潦水煎药的用意，成无己谓“取其味薄不助湿”，可入注家观点卡对照。
- 这是黄疸病“从表治”的代表思路，与后世治黄专事清利形成对照。
