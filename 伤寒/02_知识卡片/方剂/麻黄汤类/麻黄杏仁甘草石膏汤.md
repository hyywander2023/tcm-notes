# 麻黄杏仁甘草石膏汤（麻杏石甘汤）

## 一、原文（一字不改）

> **《伤寒论·辨太阳病脉证并治中》第 63 条**
> 发汗后，不可更行桂枝汤。汗出而喘，无大热者，可与麻黄杏仁甘草石膏汤。方二十六。

> **《辨太阳病脉证并治下》第 162 条**
> 下后，不可更行桂枝汤；若汗出而喘，无大热者，可与麻黄杏子甘草石膏汤。方二十四。

**校注**：两条一为汗后、一为下后，方名「杏仁」/「杏子」小异，组成相同。第 63 条方后「本云，黄耳」后疑脱“杯”或“杯”字类器名（黄耳杯为汉代饮器），原文未改。

## 二、组成

| 药 | 原文用量 | 备注 |
|----|---------|------|
| 麻黄 | 四两（去节） | |
| 杏仁 | 五十个（去皮尖） | |
| 甘草 | 二两（炙） | |
| 石膏 | 半斤（碎，绵裹） | 清肺热 |

四味药，就是麻黄汤**去桂枝、加石膏**：桂枝辛热，里热已生故去；石膏辛凉，直清肺热。麻黄配石膏，一散一清，比例是本方灵魂。

## 三、用法（原文）

> 上四味，以水七升，煮麻黄，减二升，去上沫，内诸药，煮取二升，去滓，温服一升。（第 63 条）

> 上四味，以水七升，先煮麻黄，减二升，去白沫；内诸药，煮取三升。去滓，温服一升。（第 162 条）

白话：仍是先煮麻黄去沫。**两条煎法微异：一条煮取二升，一条煮取三升**——同方而文字不同，是校勘上的一个细节点。

## 四、主治与辨证要点

- **主治**：汗下之后，邪热迫肺——「汗出而喘，无大热」。
- **辨证眼目**：三个字定位——
  - **汗出**：表已不实（区别于麻黄汤的无汗）；
  - **喘**：病位在肺；
  - **无大热**：表热不显，热郁于里（肺）。
- 两条开头都强调「不可更行桂枝汤」：汗下后虽有似表证，但病机已转肺热，再解肌就错了。

## 五、白话理解

发汗或泻下之后，表证去了，但邪气入里化热，堵在肺里。肺被热蒸，一方面**出汗**（热迫津泄），一方面**喘**（肺气不得肃降）。体表摸起来不烫，是因为热都闷在肺里。

所以这方不再发汗解表：麻黄在这里主要不是为了开毛孔，而是配着半斤石膏宣肺平喘、清透肺热。**有汗还敢用麻黄，全靠石膏压着**——这是它和麻黄汤的分工所在。

## 六、我的理解 / 存疑

- **「汗出而喘」却用麻黄，是本方的千古辨点**：柯琴“麻黄不为汗设”之说、《医宗金鉴》的表虚邪热说，与今人“宣肺平喘不必发汗”的理解，三层递进，值得建观点卡（对照 [[465-伤寒明理论]]）。
- 存疑：「无大热」究竟指“表无大热”还是“热不甚”？若是前者，则里热可以很重；两读影响石膏与麻黄的分量比例判断。
- 存疑：麻黄四两、石膏半斤（八两）比例 1:2，后世治肺热喘咳常加重石膏，与原方比例的取舍如何定？
- 第 63 与 162 条煎服法一取二升一取三升，通行本亦如此，或为传抄异文，暂记不改。
