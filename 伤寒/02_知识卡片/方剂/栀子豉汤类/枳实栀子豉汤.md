# 枳实栀子豉汤

## 一、原文（一字不改）

> **《伤寒论·辨阴阳易瘥后劳复病脉证并治》第 393 条**
> 大病瘥后劳复者，枳实栀子豉汤主之。方二。

## 二、组成

| 药 | 原文用量 | 备注 |
|----|---------|------|
| 枳实 | 三枚（炙） | |
| 栀子 | 十四个（擘） | |
| 豉 | 一升（绵裹） | 量大于栀子豉汤之四合 |

三味药 = [[栀子厚朴汤]] 去厚朴复加豆豉（或视作栀子豉汤 + 枳实）。

## 三、用法（原文）

> 上三味，以清浆水七升，空煮取四升；内枳实、栀子，煮取二升；下豉，更煮五六沸，去滓，温分再服，覆令微似汗。若有宿食者，内大黄如博棋子五六枚，服之愈。

白话：用**清浆水**（发酵米浆水）先空煮浓缩，再下药；豆豉最后下。服后覆被**微汗**。兼有宿食（伤食）加大黄如博棋子大五六枚。

## 四、主治与辨证要点

- **主治**：大病初愈后因劳复发（劳复）——余热复起，气机又滞。
- **辨证眼目**：「劳复」概念：病好后因**过劳**（体力、思虑、饮食、房劳）而复发；本方所主为余热夹气滞之轻复。
- 兼宿食加大黄：**以食积有无定药**，与承气汤证之别在程度（博棋子大的大黄块，量极轻）。

## 五、白话理解

大病刚好，身子还虚，一劳累又烧起来了——余邪未净，又添气滞。枳实宽中下气，栀子豆豉清宣余热，清浆水益胃消化。

**覆令微似汗**：让余热从表透掉。这方子显示仲景对「瘥后复发」这类状态的处理思路：轻清透泄，不峻攻不重补——恢复期人体耐受度低，用药要轻灵。

## 六、我的理解 / 存疑

- 「劳复」与「食复」（398 条「病人脉已解，而日暮微烦，以病新瘥，人强与谷……损谷则愈」）相对——393 是劳复用药，398 是食复调养，两条合读可见**瘥后调理的两分法**。
- 清浆水的性质（酸凉开胃）与空煮浓缩的煎法——瘥后用「谷物发酵水」护胃的巧思，与 397 条竹叶石膏汤的粳米后下同一关怀。
- 存疑：「覆令微似汗」而方中无解表药，汗从何来？多解为余热郁于里、清宣之后气机通畅表自和——「里和表自汗」的机转，与 230 条上焦得通津液得下胃气因和的表里互动同参。
- 瘥后劳复门共四方（烧裈散、枳实栀子豉、牡蛎泽泻散、理中丸/竹叶石膏），是「恢复期医学」的最早体系，值得整体做方法卡。
