# 栀子甘草豉汤

## 一、原文（一字不改）

> **《伤寒论·辨太阳病脉证并治中》第 76 条（节录）**
> ……虚烦不得眠，若剧者，必反复颠倒，心中懊憹，栀子豉汤主之；**若少气者，栀子甘草豉汤主之**。

## 二、组成

| 药 | 原文用量 | 备注 |
|----|---------|------|
| 栀子 | 十四个（擘） | |
| 甘草 | 二两（炙） | 益气护中 |
| 香豉 | 四合（绵裹） | |

三味药 = [[栀子豉汤]] + 甘草。

## 三、用法（原文）

> 上三味，以水四升，先煮栀子、甘草，取二升半，内豉，煮取一升半，去滓，分二服。温进一服，得吐者，止后服。

## 四、主治与辨证要点

- **主治**：栀子豉汤证兼**少气**——误治后气短不足以息。
- **辨证眼目**：「少气」是兼见语：胸膈郁热仍在，又见中气不足之短气——热扰与气伤并存。

## 五、白话理解

同样是余热郁在胸膈的虚烦，这个人气短、说话没力气——误治伤了中气。加一味炙甘草，补中益气，让清热的两味药有个后盾。

栀子豉汤家族的加减逻辑：**主证不变（虚烦懊憹），兼症定加味**——少气加甘草，呕加生姜，一张底方两个分支。

## 六、我的理解 / 存疑

- 「少气」的定位：中气虚（甘草所补）为主流解释；亦有解为热伤气者（栀子豉证本身可兼）——加甘草究竟是补虚还是调和，可入观点卡。
- 同条三方（栀子豉/栀子甘草豉/栀子生姜豉）连排，是仲景「**一底方+兼症加味**」格式的原始样本，与 40/96/317 条的或然症加减同一笔法。
- 甘草在清热方中的角色（护中防苦寒伤胃）与炙甘草汤（补益为君）不同——同一味药在不同位置的功能谱。
