# 炙甘草汤

## 一、原文（一字不改）

> **《伤寒论·辨太阳病脉证并治下》第 177 条**
> 伤寒脉结代、心动悸，炙甘草汤主之。方三十九。
>
> 甘草（炙，四两） 生姜（切，三两） 人参（二两） 生地黄（一斤） 桂枝（去皮，三两） 阿胶（二两） 麦门冬（去心，半升） 麻仁（半升） 大枣（擘，三十枚）
> 上九味，以清酒七升，水八升，先煮八味，取三升，去滓，内胶烊消尽，温服一升，日三服。一名复脉汤。

**校注**：「脉结代」＝结脉与代脉并见（结：脉来缓而时一止，止无定数；代：脉来一止，止有定数，不能自还）。「一名复脉汤」——本方别名。原文未改。

## 二、组成

| 药 | 原文用量 | 备注 |
|----|---------|------|
| 甘草（炙） | 四两 | **君药**，通经脉利血气 |
| 生地黄 | **一斤** | 全方最重，滋阴养血 |
| 大枣（擘） | **三十枚** | 全书用枣之最 |
| 麦门冬（去心） | 半升 | 润肺滋液 |
| 阿胶 | 二两 | 烊化，补血止血 |
| 麻仁 | 半升 | 润燥滋液 |
| 人参 | 二两 | 益气 |
| 桂枝（去皮） | 三两 | 通阳复脉 |
| 生姜（切） | 三两 | 通阳 |
| 清酒 | 七升 | 煎药用酒**酒多于水** |

结构：**滋阴养血药群＋益气通阳药群**——阴中求阳、静中寓动，复脉之枢在桂枝。

## 三、用法（原文）

> 上九味，以清酒七升，水八升，先煮八味，取三升，去滓，内胶烊消尽，温服一升，日三服。

白话：清酒七升＋水八升（酒量过半）先煮八味，最后烊入阿胶。**以酒煎药**是本方重大特色——酒力行药势、通血脉。

## 四、主治与辨证要点

- **主治**：心之阴阳气血两虚，**脉结代、心动悸**——伤寒耗伤心气心阴之心律失常。
- **辨证眼目**：
  - 「心动悸」：心慌剧烈、筑筑然悸动（非一般心悸）。
  - 「脉结代」：脉律不齐、时有间歇——**脉诊定方**的典范条文。
- 178 条（结阴代阴之脉理：「脉按之来缓，时一止复来者，名曰结阴……」）是本条的理论注脚。

## 五、白话理解

伤寒多日，汗下失治，心的气血被耗空了。心气心阳不足则鼓动无力——脉跳跳停停；心血心阴不足则心失所养——悸动不安。

治疗双管齐下：大队地黄、麦冬、阿胶、麻仁滋阴养血，填物质基础；人参、桂枝、甘草、姜枣益气温阳，给跳动供能。再用七升清酒煎药，让药力直入血脉。物质与动力都到位，脉律自然恢复——所以**别名「复脉汤」**。

## 六、我的理解 / 存疑

- 本方是**中医治心律失常之祖方**：结代脉对应的期前收缩/房颤类疾病，至今仍是临床高频方（「炙甘草汤证」几乎是心悸动+脉结+舌光红少苔的同义词）。
- 生地一斤、大枣三十枚、清酒七升三个「全书之最」叠加——剂量结构学样本：**滋阴补液的极端配置**，与四逆辈的极端温阳配置对称。
- 桂枝三两在九味大队滋阴药中的角色之争：柯琴「阴药太重」之评 vs 「无桂枝则不成复脉」之说——注家观点卡靶子。
- 后世化裁线：→《温病条辨》加减复脉汤（去参桂姜枣，加白芍，纯滋阴）→ 一甲/二甲/三甲复脉汤、大定风珠——**复脉汤家族树**，专题卡素材。
- 「心动悸」与 64 条「发汗过多，其人叉手自冒心，心下悸欲得按」的桂枝甘草汤证对读：轻证单补阳，重证阴阳并补。
