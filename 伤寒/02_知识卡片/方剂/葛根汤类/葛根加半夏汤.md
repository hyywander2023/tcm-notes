# 葛根加半夏汤

## 一、原文（一字不改）

> **《伤寒论·辨太阳病脉证并治中》第 33 条**
> 太阳与阳明合病，不下利，但呕者，葛根加半夏汤主之。方三。

## 二、组成

| 药 | 原文用量 | 备注 |
|----|---------|------|
| 葛根 | 四两 | |
| 麻黄 | 三两（去节） | |
| 甘草 | 二两（炙） | |
| 芍药 | 二两 | |
| 桂枝 | 二两（去皮） | |
| 生姜 | 二两（切） | |
| 半夏 | 半升（洗） | **加**，降逆止呕 |
| 大枣 | 十二枚（擘） | |

八味药 = [[葛根汤]] + 半夏。注意生姜由三两减为二两。

## 三、用法（原文）

> 上八味，以水一斗，先煮葛根、麻黄，减二升。去白沫，内诸药，煮取三升，去滓，温服一升。覆取微似汗。

白话：同葛根汤法，先煮葛根麻黄去沫，覆被取微汗。

## 四、主治与辨证要点

- **主治**：太阳阳明合病，邪不下趋而为呕——「不下利，但呕」。
- **辨证眼目**：与第 32 条对照：合病**下利**用葛根汤（葛根升清即止利），**不下利但呕**则加半夏降逆。一升一降，皆从表解。
- 「合病」而治法全在太阳一面，呕与利只是邪气内扰阳明的外在表现。

## 五、白话理解

同样是表寒闭住了，这个人的反应不是往下（下利）而是往上（呕吐）——胃气被邪气顶得上逆。所以葛根汤开表为主，加半夏把上逆的胃气压下去。

第 32、33 两条合读，最能看出仲景「治病求本」：呕、利是支流，表闭是源头，表一开，阳明自安。

## 六、我的理解 / 存疑

- 半夏止呕靠「降」，葛根止利靠「升」——一升一降都在一张底方上做加减，这是「方证对应」的最小改动示例。
- 存疑：呕而兼利者（两条证并见）如何取舍？原文未言，注家有主张二方并用之理者，可对照注本。
- 本方是理解「太阳阳明合病三种走向」（利/呕/喘而胸满用麻黄汤）的样本之一。
