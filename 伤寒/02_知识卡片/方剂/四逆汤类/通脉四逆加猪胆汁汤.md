# 通脉四逆加猪胆汁汤

## 一、原文（一字不改）

> **《伤寒论·辨霍乱病脉证并治》第 390 条**
> 吐已下断，汗出而厥，四肢拘急不解，脉微欲绝者，通脉四逆加猪胆汁汤主之。方六。

## 二、组成

| 药 | 原文用量 | 备注 |
|----|---------|------|
| 甘草 | 二两（炙） | |
| 干姜 | 三两（强人可四两） | |
| 附子 | 一枚（生，去皮，破八片，大者） | |
| 猪胆汁 | 半合 | 咸苦反佐 |

四味药 = [[通脉四逆汤]] + 猪胆汁。

## 三、用法（原文）

> 上四味，以水三升，煮取一升二合，去滓；内猪胆汁，分温再服，其脉即来。无猪胆，以羊胆代之。

白话：药煮好后**兑入猪胆汁**服。服后脉恢复为愈兆。无猪胆可用羊胆代替——原文自带的替代方案。

## 四、主治与辨证要点

- **主治**：霍乱吐利俱停之后的阳亡阴竭——「吐已下断，汗出而厥，四肢拘急不解，脉微欲绝」。
- **辨证眼目**：吐利「断」不是好转，是**无物可吐、无津可利**——阴液枯竭之象；汗出肢厥拘急、脉微欲绝，阳随液脱。
- 与 389 条「既吐且利……内寒外热脉微欲绝」四逆汤证对照：彼阳衰，此**阳亡加阴竭**。

## 五、白话理解

上吐下泻到极点之后突然都停了——不是病好了，是身体的津液吐光泻光了。阳气也跟着液体要脱，脉几乎摸不到，四肢抽紧。

这时单用辛热药有个两难：阳要救，但大热之药进去，阴竭之体格拒不受，甚至催促虚阳外脱。所以加一味猪胆汁——咸苦性寒，**引导热药入阴**，使辛热不被拒于外。这就是「**反佐**」法：以寒药少许为热药开路。

## 六、我的理解 / 存疑

- 反佐法是本方对中医配伍理论的独特贡献：《内经》「甚者从之」的落地样本，与 [[白通加猪胆汁汤]]（315 条）同为反佐双璧。
- 「吐已下断」的判断价值：症状「停止」≠ 向愈——识别假性平静是危证辨别的关键一课，与 315 条「脉暴出者死，微续者生」同一思维。
- 存疑：人尿与猪胆汁的取舍（白通加猪胆汁汤有人尿，本方无）——两方反佐物之异是否有深意？
- 猪胆汁的取材与今用替代（多径用童便或去之）属沿用层面。
