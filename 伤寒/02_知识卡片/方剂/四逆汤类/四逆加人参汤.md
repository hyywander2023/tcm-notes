# 四逆加人参汤

## 一、原文（一字不改）

> **《伤寒论·辨霍乱病脉证并治》第 385 条**
> 恶寒、脉微而复利，利止，亡血也，四逆加人参汤主之。方一。

## 二、组成

| 药 | 原文用量 | 备注 |
|----|---------|------|
| 甘草 | 二两（炙） | |
| 附子 | 一枚（生，去皮，破八片） | |
| 干姜 | 一两半 | |
| 人参 | 一两 | 益气固脱生津 |

四味药 = [[四逆汤]] + 人参。

## 三、用法（原文）

> 上四味，以水三升，煮取一升二合，去滓，分温再服。

## 四、主治与辨证要点

- **主治**：阳虚液脱——「恶寒、脉微而复利，利止，亡血也」。
- **辨证眼目**：利止非病愈，是**津液（血）亡失无物可利**——「亡血」指阴液耗竭。与 390 条「吐已下断」同一逻辑：症状消失的假象。
- 阳虚（四逆证俱）+ 阴伤（利止亡血）→ 回阳必须同时益阴固脱。

## 五、白话理解

拉肚子拉到停了——不是好转，是身体里没有液体可拉了。阳气本来就虚（恶寒脉微），阴液又枯，单回阳则津液不复。

四逆汤原方加一味人参：附子干姜把火点起来，人参把烧干的津液固住、把元气补上——**阳与阴一起救**。

## 六、我的理解 / 存疑

- 「利止，亡血也」五字是危证辨证的精髓——与 390 条「吐已下断」、315 条「利止脉不出」构成一组「**假性好转**」条文，值得合读做方法卡。
- 存疑：四逆汤加人参与茯苓四逆汤（69 条）的差异——彼治烦躁（阴阳俱虚而扰神），此治利止亡血（偏液脱），加味同而主治异。
- 「亡血」在此指亡津液而非失血——经方「血」常兼指阴液，训诂点。
- 后世「回阳固脱」法用人参配附子的通例（参附汤类）即源于此。
