# 茯苓四逆汤

## 一、原文（一字不改）

> **《伤寒论·辨太阳病脉证并治中》第 69 条**
> 发汗，若下之，病仍不解，烦躁者，茯苓四逆汤主之。方三十二。

## 二、组成

| 药 | 原文用量 | 备注 |
|----|---------|------|
| 茯苓 | 四两 | 用量最重 |
| 人参 | 一两 | |
| 附子 | 一枚（生用，去皮，破八片） | |
| 甘草 | 二两（炙） | |

五味药 = [[四逆汤]] + 茯苓、人参。

## 三、用法（原文）

> 上五味，以水五升，煮取三升，去滓，温服七合，日二服。

## 四、主治与辨证要点

- **主治**：汗下后阴阳两虚兼水气内扰之烦躁。
- **辨证眼目**：「烦躁」见于误治后，且「病仍不解」——阴阳俱伤。与第 61 条干姜附子汤证（纯阳虚之昼烦夜静）、第 68 条芍药甘草附子汤证（阴虚之恶寒）三方并列，是「**误治后烦躁的虚证分型**」一组。
- 茯苓四两为君：既利水宁心，又佐人参生津。

## 五、白话理解

又发汗又攻下，阴阳两伤：阳虚则心神失养，阴虚则虚火内扰，还可能有水气乘虚上凌——所以烦躁不安。

四逆汤回阳，加人参救阴，重加茯苓把水气渗下去、把浮扰的心神安下来。**阳、阴、水三路同治**的烦躁方——与三承气（实热烦躁）、大青龙（表闭里热烦躁）方向完全相反，虚证烦躁的代表。

## 六、我的理解 / 存疑

- 烦躁的虚实寒热鉴别网络：大青龙汤（表寒里热）、承气类（腑实）、栀子豉汤（虚烦有热）、干姜附子汤（纯阳虚）、茯苓四逆汤（阴阳两虚）——六大烦躁的鉴别是太阳病篇误治变证的收束性主题，建议做方法卡「烦躁六方」。
- 存疑：本证烦躁中茯苓的分量（水气是否必具）——原文未言心悸小便不利，重用茯苓是「宁心」还是「利水」，注家有分歧。
- 「病仍不解」四字：指表证未除还是病情依旧？若表未解而径投温补，与「先表后里」原则的关系可议。
