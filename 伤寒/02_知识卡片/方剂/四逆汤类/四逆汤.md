# 四逆汤

## 一、原文（一字不改）

> **《伤寒论·辨太阳病脉证并治上》第 29 条（节录）**
> ……若重发汗，复加烧针者，四逆汤主之。

> **《辨少阴病脉证并治》第 388 条（吐利汗出条，通行本）**
> 吐利汗出，发热恶寒，四肢拘急，手足厥冷者，四逆汤主之。

## 二、组成

| 药 | 原文用量 | 备注 |
|----|---------|------|
| 甘草 | 二两（炙） | |
| 干姜 | 一两半 | |
| 附子 | 一枚（生用，去皮，破八片） | 生用回阳 |

三味药。**附子 + 干姜 + 甘草**——回阳救逆的最小核心。

## 三、用法（原文）

> 上三味，以水三升，煮取一升二合，去滓，分温再服。强人可大附子一枚、干姜三两。

白话：分两次温服。**体质强壮者可加大附子、加干姜**——原文自带剂量随人调整的示范。

## 四、主治与辨证要点

- **主治**：少阴阳虚阴盛之寒厥——四肢厥逆、下利清谷、脉微欲绝、恶寒踡卧。
- **辨证眼目**：「四逆」的来历：阳气衰微不能达于四末。**生附子**（不炮）走窜回阳之力最锐。
- 与 [[四逆散]]（气郁致厥）之辨：寒厥兼见下利清谷、脉微；与 [[白虎汤]] 热厥（脉滑）之辨：厥同而脉证全反。

## 五、白话理解

阳气是身体的火炉，火炉快熄了：手脚先凉（四逆），吃啥拉啥（下利清谷），脉细得快摸不到。这时唯一要务是**生火**：生附子点火的猛将，干姜守住中焦的炉膛，甘草坐镇让药力持续平稳——辛甘大热，把残阳从悬崖边拉回来。

## 六、我的理解 / 存疑

- 附子生用（生附子）是四逆汤类与麻黄附子细辛汤类（炮附子）的分界——生者回阳救逆，炮者温经扶阳，炮制改变药效方向。
- 第 92 条「病发热头痛，脉反沉，若不瘥，身体疼痛，当救其里」——表证见沉脉即转四逆，**凭脉转方**的范例。
- 存疑：29 条四逆汤用于「重发汗复加烧针」，是预防性救逆还是已成四逆？条文极简，注家有分歧。
- 四逆汤族（四逆、通脉四逆、白通、茯苓四逆、四逆加人参）的层层加码结构，值得做方法卡。
