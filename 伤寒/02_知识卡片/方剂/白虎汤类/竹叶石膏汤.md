# 竹叶石膏汤

## 一、原文（一字不改）

> **《伤寒论·辨阴阳易瘥后劳复病脉证并治》第 397 条**
> 伤寒解后，虚羸少气，气逆欲吐，竹叶石膏汤主之。方六。

## 二、组成

| 药 | 原文用量 | 备注 |
|----|---------|------|
| 竹叶 | 二把 | 轻清余热 |
| 石膏 | 一斤 | |
| 半夏 | 半升（洗） | 降逆止呕 |
| 麦门冬 | 一升（去心） | **用量独重**，养阴生津 |
| 人参 | 二两 | |
| 甘草 | 二两（炙） | |
| 粳米 | 半升 | |

七味药 = [[白虎加人参汤]] 去知母，加竹叶、麦冬、半夏——清热之力减，养阴之力增。

## 三、用法（原文）

> 上七味，以水一斗，煮取六升，去滓；内粳米，煮米熟，汤成去米，温服一升，日三服。

白话：药先煮好去渣后**再下粳米**煮米熟——与白虎汤同煮不同，粳米后下的煎法细节。

## 四、主治与辨证要点

- **主治**：热病瘥后，气津两伤、余热未清——「虚羸少气，气逆欲吐」。
- **辨证眼目**：大病初愈人瘦弱乏力（虚羸少气），胃中余热上逆想吐（气逆欲吐）——==🟡**虚多热少**==，与白虎汤证纯热无虚对照。
- 这是全书记载的最后几张方之一，属「瘥后调理」门。

## 五、白话理解

烧退了、病好了，但人被消耗得厉害：瘦、没力气、胃里还有点虚热顶着想吐。这时不能再用白虎猛清（正气已虚），也不能纯补（余热未尽）。

竹叶、石膏轻轻地清掉残余的热，麦冬大剂量把烧掉的津液补回来，人参益气，半夏降逆，粳米甘草养胃——**清补并行、以补为主**。后世「热病后期调理」的法定代表方，温病学派「甘寒生津」一脉由此而出。

## 六、我的理解 / 存疑

- 麦门冬一升（约舍数十克）为全方最重——从白虎汤「以清为主」到本方「以润为主」的转变，全在用量倾斜上见分晓。
- 半夏性温燥，配大剂麦冬则「润而不腻、降而不燥」——**反佐式配伍**的样本。
- 与 [[炙甘草汤]]（177 条，亦治虚羸脉结代）同属病后滋阴方，一偏胃肺气津、一偏心之阴阳，可对看。
- 「气逆欲吐」之呕与少阳喜呕、水饮呕的鉴别：本证无寒热往来、无心下痞硬，纯由虚热上冲。
