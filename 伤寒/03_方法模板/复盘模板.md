# 复盘：〔标题〕

> 适用：项目复盘（一个任务做完了）、周/月复盘（一段时间的学习）、踩坑复盘（一个具体问题）。复制本模板到 `05_复盘反馈/`，文件名格式：`YYYY-MM-DD-复盘对象.md`。

## 一、当初想干什么

- 任务/目标是什么，当时打算怎么做。
- 如果有任务看板，链接到 [[04_任务项目]] 里的对应文档。

## 二、实际做成了什么（只写事实）

- 完成了什么、数量、关键数字。
- 没做完的、中途改主意的，如实写。

## 三、做得好的 → 沉淀为规则

- 哪些做法值得保留？**每一条都尽量转成"下次照做"的具体规则**，能进 [[03_方法模板]] 的就进去，能写进工作约定的就写进约定。
- 规则写成一句可执行的指令，不要写成感想。

## 四、踩的坑 → 教训与规避

| 坑 | 当时发生了什么 | 以后怎么避免 |
|----|--------------|------------|
|    |              |            |

## 五、新发现与新问题

- 过程中发现的新知识点、新争议、新线索——这是知识库最值钱的部分。
- 能建卡的建卡，能入任务清单的入 [[04_任务项目]]，别让它们只留在这篇复盘里。

## 六、下一步行动

- [ ] 具体可执行的下一步（写清楚建什么、改什么、放哪）。
